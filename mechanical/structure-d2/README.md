# D2 ペンダントケースの固定・音道検討

**試作設計。製造リリースではない。** 外形はD25.5×14.5mmのまま、D1基板配置に対して装着・固定の形状を追加した。部品は簡略包絡、電池は未調達の予約形状。

- 下ケースの上側（USBと反対側）へ直径1.6mmの横向き紐通しを内蔵。外付けの耳を増やさず、内部を補強。紐そのものと結び目は外形寸法に含まない。
- 基板下面に3か所の支持座を追加。厚さ0.1mmの接着材を仮置きした。銘柄・保持力・交換方法は未確定。
- 蓋は向かい合う2か所のバヨネット形状を検討。15°回転して保持する形状だが、緩み止め・保持力・寸法公差は未評価。
- マイクの実際のPCB音孔位置(3, −7.39)mmから外周へ音道を追加。硬い樹脂と基板が接するだけで気密を保証せず、最終的にガスケットの調達と感度/衣擦れの比較試験が必要。

基板支持座と音道は、現在の簡略部品包絡との干渉を避けた配置。全品の実体STEP、ハーネス、はんだ盛り、電池膨らみを含む総合干渉検査ではない。基板の配線に伴って部品を動かした場合は再設計する。

## 印刷前に確定する項目

バヨネット溝の外側肉厚は最小約0.65mm、蓋の内周リムは約0.6mm。一般的なFDMで寸法どおり成立するとは扱わない。樹脂方式/材料、造形方向、溝の清掃性、積層強度、嵌合公差を選定し、部分試験片から確認する。蓋保持に問題があれば外形より固定の確実さを優先して改版する。

電池固定、LED導光、ボタン延長、肌側の角の仕上げ、紐の強度と装着安全、USB挿抜荷重の支持、NTC接触材が残っている。現状のSTEPをそのまま完成ケースとして発注しない。

基板と一体の発注条件は[発注残件](../../docs/d1-order-gates.md)。旧D1は比較原本として残す。
