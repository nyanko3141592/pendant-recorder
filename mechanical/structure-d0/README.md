## 寸法と変更

| 項目 | 旧C0 | D0検討案 |
|---|---:|---:|
| ケース外形 | 23.8×34×14mm | 25.5×25.5×14.5mm |
| 基板 | 21×31×0.8mm | 23×23×0.8mm、角R2 |
| 電池 | 110mAh、長方形完成パック | 150mAh丸形完成パック候補、未調達 |
| 電池接続 | JST PH | JST SH横型＋業者製短尺線候補 |

長さ8.5mm減、幅1.7mm増、厚さ0.5mm増。角丸外形の体積概算は旧C比17.8%減。Omiの25.5mm径×15mm円柱近似と比べると約21.1%大きい。**Omiと同じ縦横範囲であって、同じ体積ではない。** 500円玉は径26.5mmのスケール参考、厚さ/模様は簡略化。旧比較のOmi径25mmから、参照資料の25.5mmへ統一した。

## モデルを読む

金色は**完成パックの目標包絡D17×6.1mm**。メーカーが保証する完成品寸法ではない。GRP1654M1単セルD16×5.4mmを基に余裕を設けた設計枠で、保護回路の配置次第で変更が必要。オレンジは側面保護回路と配線用の予約領域。青緑の小片はNTC用絶縁熱伝導パッド候補。

底1.0mm、電池の下端1.2/上端7.3mm、基板下面9.1/上面9.9mm、蓋下面13.5/上面14.5mm。裏面部品高さ最大1.5mmを仮定すると電池との隙間0.3mm、USB高さ3.2mmを仮定すると蓋との隙間0.4mm。これらは公差・はんだ・実部品3D照合前の名目値。金色の電池寸法やこの隙間で製造を確定しない。

部品のXY位置は `hardware/omi-fit-d0/placement.json` と共通。3D部品は簡略包絡で、メーカーSTEPではない。69部品＋7接点群を描画。PCBの穴、音道、蓋固定、ストラップ、LED導光、押しボタン延長、完成線材経路は未設計/未検証。従って装着部込みの完成サイズを保証するモデルではない。

## 稼働時間の計算

`時間 = 公称容量 × 使用可能割合 ÷ 電池端子の平均電流`。

150mAhの70%を使えると仮定すると5mAで21h、6mAで17.5h、7mAで15h。図の薄い帯は使用可能割合50〜85%を変えた仮定の範囲で、統計的信頼区間ではない。充放電の非線形モデル、SPICE、温度解析、ファーム実行、実電池測定は行っていない。平均5mAは達成値ではなく開発目標。

## 再生成

`python3 generate.py` → `solidcraft-cli run assembled.json --save assembled.solidcraft --out assembled.step --quiet`。分解は同様に `exploded.json` を使う。`compare.py` で比較モデル、`plots.py` で配置図と電流感度図を生成する。独自成果物MIT、参照フットプリントは元ライセンスに従う。
