# Rev E0 構造モデル

SolidCraftの組立/分解モデルとSTEP、分解画像。28×34×13.8mmの収納検討枠。内部は25×31mm基板、15.5×27×4.2mmのXE電池包絡、配線予約空間、75個の部品包絡。

部品はフットプリント位置を用いた簡略包絡で、メーカーSTEPではない。電池線長、曲げ、膨張、はんだ、全公差、支持部との干渉、蓋固定、紐固定、音道、ボタン・LEDアクセスが未完了。3Dプリント発注用ではない。旧円形D2より外形包絡体積は増えており、小型化完了ではない。

`generate.py`からJSONを生成しsolidcraft-cli runでSolidCraft/STEPを出力。回路の充電温度条件が未解決。16h実測未実施。
