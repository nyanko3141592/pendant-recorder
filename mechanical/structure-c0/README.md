# Rev C0 収納検討 — 23.8×34×14mm

SolidCraftで生成した構造案。実PCBのplacement-report.jsonを読み込み、部品のXY位置・実装面を反映。部品高さ・外形は簡略包絡体で、仕入先の3Dモデルによる公差照合ではない。**製造用ケースではない。**

- 基板21×31×0.8mm、上面7.7mm、下面6.9mm。
- 保護付き110mAh電池の最大寸法15.5×27×4.2mmをz=1.2〜5.4mmに置く。裏面部品用空間1.5mmは高さ・膨張・絶縁を含め最終検証待ち。
- USBとPHコネクタを基板上面の同じ端へ並べる。PHの高さを含め、ふた下面13mmまでの余裕を設ける。現段階の収納枠は厚さ14mm。
- 茶色のブロックはPH嵌合プラグの暫定予約空間、オレンジの側帯は未加工線材の予約空間。正確な嵌合形状や100mmリードを曲げて収めた証明ではない。
- 基板支持は概略。ふたの固定、電池保持/膨張、NTCを電池へ当てる熱伝導パッド、底面マイクの側面への音道、装着部は未完了。
- TC2030ポゴ接点と穴はPCB原本にあるが簡略CADの基板には再現していない。書込みは電池組込み前を想定し、完成治具の確認が必要。
- 底1mm・ふた1mm・側壁1.2mmは樹脂プリント案。強度、印刷公差、挿抜耐久は未検証。
