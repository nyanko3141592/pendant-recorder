# Compact 100mAh v5 — 外観とサイズ・収納モデル

外形26×31×14mm。基板24×27×0.8mm、電池ダミー15×17×6mm。角丸ケース、内蔵紐穴、USB-C開口、ボタン/LED開口、基板支持レール。底面マイク穴を実PCBのU8音孔座標へ登録。組立STEPの縦音道は予約部材で、実際のガスケット/密閉と音響は未検証。

assembled.step / exploded.stepが組立/分解3D。assembled.png / exploded.pngがプレビュー。comparison.pngは左Omi直径25×15mm円柱近似、中央v5、右旧B20×39×14.5mmを共通座標/縮尺で比較。Omiの実形状再現ではない。

print/に外形一体、ケース本体、蓋、電池、部品包絡付きPCB、裸PCBの6種類のSTL/3MFを格納。PRINT-README.txtを参照。ユーザーの試し刷り・仮組み用であり、実電池を充電して使える完成ケースではない。

当初目標24×29×14mmでは、今回の自動配置と電池禁止領域を両立できず26×31mmへ拡大した。不可能と証明したわけではない。旧B比では8mm短く0.5mm薄いが6mm幅広く、直方体体積は11.284cm³対11.310cm³でほぼ同じ。Omi円柱近似7.363cm³より大きい。高さ上限15mmには名目値で収まるが、製造公差・電池膨張・実部品最大高さの適合は未完了。

部品87点は実KiCadフットプリントから幅/長さを取得。部品高は種別に基づく仮定で、メーカーSTEPではない。裏面電池予約領域との部品包絡干渉は0件（J3/TPの薄い接点は除外）。ケーブル予約領域は仕入先完成ハーネスの保証ではない。NTC追加/短尺配線/コネクタ変更品の完成外形を確認後に更新する。

USB上面12.56mm、蓋下面13mm、名目余裕0.44mm。上下公差各0.2mmの仮定では0.04mmしか残らないため、量産寸法として確定していない。部品/USBの公差検証、開口のケーブル樹脂干渉、蓋保持と紐強度、電池固定は試験残件。

電池基準はYDL601515の商品掲載（保護回路込み15×17×6mm）。標準PH2pinのままでは回路J2へ接続できない。3pin NTC付き短尺完成ハーネスは調達未確定。
