# Compact 100mAh v5

100mAh YDL601515候補に合わせた回路図と24×27×0.8mm・6層の配置/配線試作。87フットプリント、実装80点。USB-C、16h目標、36h保存、暗号化を維持。実機動作・調達・発注可否は未成立。正本はorder-status.json。

電気回路はcharge-guard-v4を継承。MCU/記録媒体/充電ガードを省略して小さく見せていない。電池変更に伴うNTC定数と充電電圧/終止の適合確認は未完。J2はMolex 3pin完成NTCハーネスを必要とするが、YDL標準品はPH2pinであり、そのまま接続不可。短尺3pin/NTC付き完成品の供給・価格・寸法確認が必要。約22mA充電設定は公称100mAh/最大0.5Cの掲載値内だが、これだけで充電適合とはしない。

基板裏面のx=4..20,y=2..20mmは電池予約領域。J3/TPは薄い基板接点のため除外。書込み時は電池を外す。既存のv4/v3回路や別チャットの機構原本は変更していない。

create.pyは回路図、layout.py --discard-routingは配置/DSNを生成。layout再実行は配線を破壊する。finalize.pyはSES再取込みで修正済み配線を上書きする。repair系は実験履歴であり、現在板への再実行は意図した変更か確認すること。ERC/DRCは電気的動作、USB品質、温度ガード、16h達成の保証ではない。

機構モデルと個別STLはmechanical/compact-100-v5。外形26×31×14mm。当初24×29×14mmはこの配置で成立せず、幅/長さを拡大。旧Bより8mm短く0.5mm薄いが6mm広い。直方体包絡体積は旧Bとほぼ同じで、大幅な小型化を達成した版ではない。さらに体積を減らすには統合電源IC/充電ガード等の回路再設計が必要。

ファームの平均電池電流目標3.5〜4mAは未実装/未実測。100mAhの70%を使用可能と仮定した16h条件は4.375mA以下。DMA/休止/バッチ保存/暗号化の実測が必要。

検査結果: ERC0、クリアランス等DRC0、回路図等価性0、未接続0。1506配線/ビア。最後のPDM_DATAと周辺4信号の内層経路を再構成して接続し、DRCを再検査した。0.30mmビアの試行は既存加工ルールと不一致のため不採用、最終板は0.35/0.15mmへ戻した。全接続は完了したが、電気レビュー・製造可能判定は未完。
