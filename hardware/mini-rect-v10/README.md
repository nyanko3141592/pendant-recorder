# mini-rect-v10 — 角丸四角の比較配置

2026-10-25。円形固定を撤回し、四角い電池と基板を効率よく収めることを優先した。前案はOmiの小ささと円形を結び付けすぎていた。同じ機能・電池・部品数で配置をやり直した。

| 模型 | 外形 mm | 平面角R mm | 正面面積 mm² |
|---|---|---|---|
| 印刷基準fit-v7 | 26×31×14 | 5 | 784.54 |
| 丸形v9 | 26×28×14 | 12.9 | 585.15 |
| 角丸四角v10 | 23×25×14 | 3.5 | 564.48 |
| Omi寸法ゲージ | D25.5×15 | 円 | 510.71 |

v10はv9より幅/縦とも3mm小さく、正面面積3.53%減。印刷基準比28.05%減。幅×縦の外接矩形だけで面積/体積減を表現しない。Omiは実CADでなく寸法参考の円筒模型。

回路接続・部品選定はmini-usb-v9と同一。68実装点、74フットプリント、USB-C有線書き出し/充電、無線なし、16h目標、温度保護、100mAh候補電池を維持。4層21×23×0.8mm、角R2.5の未配線基板へ再配置。電池包絡15×17×6mm、組立中心11.5/11.5mm、z1.4〜7.4mm。基板下面8.5mm。

## 検証の範囲

- ERC0、幾何DRC0、回路図等価性0。ただし未配線175件。v9の試験配線を移植したものではない。発注不可。
- `placement.json`の実フットプリント外接矩形＋v9と同じ高さ包絡で模型を生成。電池完成寸法・膨張・配線取り回し・嵌合コネクタ包絡は未確定。
- ケース/蓋/部品/電池の重なりは`mechanical/mini-rect-v10/clearance-summary.json`を正本とする。量産の爪、紐穴、防水、音道、締結は未設計。ケースはテープ仮止め。
- 電池持続時間・保存容量・部品欠品など、`../mini-usb-v9/README.md`と`review.json`の未解決点を引き継ぐ。小型化で16時間達成を保証しない。
