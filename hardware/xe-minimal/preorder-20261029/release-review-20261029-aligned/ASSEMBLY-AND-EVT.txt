## 5台EVTの順序

全台を **Gate A → Gate B → Gate C → Gate D/E → Gate F** の順で試験する。Gate Aのrail短絡は実セルを使わず100–110mA制限の電池シミュレータで行う非破壊スクリーニングであり、通常の0→5.25V起動で電源の電流制限が作動しない条件とは分けて記録する。6/9/12/20V異常入力も実セルを外して行う。

Gate Cの10/25/35℃・各16時間を全5台で完了する前に、Gate Fの50N引張、疲労、摩耗、落下を行わない。異常発熱、発煙、臭気、漏液、目視損傷、規格外測定が一つでも出た個体は直ちに停止してFAILとし、Gate Cへ再利用しない。Unit 1で各非破壊手順を確認してから同じacceptance IDでUnit 2–5へ展開する。

## Gate A — 無通電・電気安全

- USB shield、VBUS、BAT、SYS、V3V3、GND間の意図しない短絡がない。
- 電池コネクタの1:+、2:10kΩ NTC、3:-を受入検査で確認する。P2は25℃で公称10kΩ付近かつ温度上昇で抵抗が単調減少すること、逆挿入不能性、完全嵌合、引抜き動作を実物で確認する。
- 0Vから5.25Vまで電流制限電源で起動し、過電流、発熱、発振、rail過電圧がない。
- MCU停止、reset保持、brownout、ファーム未起動の各状態で充電permissionが成立しない。
- 電池NTC open/short、比較器入力open/short、Q4 gate stuck-low相当では充電しない。

合格条件: 規定外電圧、発煙、臭気、目視損傷、充電誤許可が全て0件。通常の0→5.25V起動では電源の電流制限作動も0件。意図したrail短絡試験では100–110mA制限の作動自体を異常扱いせず、1秒以上保持後も表面60℃以下、発火・発煙・臭気・破裂・漏液なし、短絡除去後に安全復帰することを合格条件とする。異常が1件でもあれば以降停止。

## Gate B — 充電・温度・USB異常

- 5.0V公称と4.75/5.25Vで、入力電流、電池電流、電池電圧、NTC温度、電池表面温度、IC温度を同時記録する。
- 異常入力試験は実セルを外し、電池シミュレータと電流制限電源を使う。NCP360入力を6V、9V、12V、20Vへ段階的に上げ、各電圧を0.1V/µs、1V/µs、10V/µsの入力slewで試す。NCP360のVIN/VOUT、`/VBUS_OVP`、`/VBUS_CHARGER`、入力電流、NCP360/TPS2552/充電IC温度を時刻同期で記録する。測定不確かさをピーク値へ加算し、それでも`/VBUS_OVP`と`/VBUS_CHARGER`が6.500V未満でなければ不合格とし、部品変更または回路変更を必須とする。各段階で下流推奨動作範囲または絶対最大定格の超過、損傷、発煙、臭気、異常発熱がないことを確認する。実セル接続試験へ進むのはこの試験合格後とする。
- TPS2552のVIN、VOUT、入力電流を十分な帯域で同時取得し、通常起動、空電池起動、ケーブル挿抜、出力短絡、充電開始・停止における電圧dip、overshoot、発振、50～100mA電流制限、ラッチオフを記録する。短絡中に自動再起動せず、USB入力を一度除去して再印加した後だけ安全に復帰することを確認する。C31/C32の実装値と5.25V DC bias時の実効容量を部品データまたは実測で確認する。C33は実装ロットを特定し、35V定格と20V DC bias時の実効容量をメーカー資料または実測原データで確認する。型番・ロットに対応しない一般値だけでは合格にしない。
- 工場書込み候補条件としてJ2を空のままJ1へ電流制限5.0Vを供給し、J3 pin1へ電力を注入せずVTREFとしてのみ測定する。安定したV3V3、SWD接続、reset保持中のcharge request LOW、電池未接続による実充電0mA、異常発熱なしを5台全てで確認できなければ、この電源方式を業者手順へリリースしない。
- 低温側は0–12℃、高温側は25–45℃を十分遅い温度掃引と段階保持で確認する。設定点付近では最低30分保持し、停止温度、復帰温度、チャタリング、最大熱遅れを測る。
- 5台それぞれのNTC抵抗を0℃、10℃、25℃、35℃、45℃で記録し、ケース公差と電池厚公差を含む完成状態で同じ試験を行う。
- USB挿抜、瞬断、D+/D-短絡、CC open、VBUS 0→5.25V、USB suspend/resume、MCU resetを試す。
- 固定100mA入力制限の下で、USB接続後の列挙前とconfiguration解除後も、温度条件が安全なら9–11mA充電し、製品全体のUSB入力が100mA以下であることを時刻同期で記録する。データ線を使わない一般的なUSB-C電源+C-to-Cケーブル、およびUSB-A電源+A-to-Cケーブルでも、列挙なしで同じ充電条件を5台全て確認する。物理切断またはsuspendでは直ちに充電電流0mAへ戻ることを確認する。
- 充電終止、再充電、満充電保持、過放電からの復帰を確認する。
- 選定した停止電圧へ到達させ、暗号化tailのcommit、filesystem unmount、USB/audio/storage停止後に、USB未接続ならPA0 `VBUS_N`をactive-low WKUP1としたStandbyへ入ることを確認する。完成品の電池電流は150µA以下とする。USBを接続するとreset起床し、1000ms以内に9–11mA充電へ移行し、完成済みfileを失わないことを5台全てで確認する。これは無期限保管保証ではなく、電池保護回路の遮断・復帰挙動も別途記録する。

合格条件: 電池表面が0℃以下または45℃以上では充電電流が流れず、5～40℃内へ戻るまで自動復帰させない安全側ヒステリシスを実測できること。境界チャタリング、reset中許可、強制電流制限時の50mA未満または100mA超、短絡中の自動再起動、6/9/12/20V異常入力時の下流推奨動作範囲・絶対最大定格超過、持続発振、危険なovershoot、電池メーカー上限超過、ケース内異常発熱を認めない。NTC抵抗、表面温度、比較器出力、充電電流、NCP360およびTPS2552入出力波形の時刻同期記録が欠けた個体は未確認とする。

## Gate C — 110mAhで連続16時間録音

- cutoff characterizationで使ったP1～P5をU1～U5へ同番号で固定し、途中で交換しない。電池lotだけでなく試験IDを記録し、別電池への差替えを合格扱いにしない。
- 温度run順はU1=`25→10→35℃`、U2=`10→35→25℃`、U3=`35→25→10℃`、U4=`25→35→10℃`、U5=`10→25→35℃`とし、サイクル劣化が一つの温度へ偏らないようにする。順序変更はdeviationとしてFAIL判定前に記録し、結果を見て順序を選ばない。
- 各run前に完成品自身のBQ25185、4.1V設定、9–11mAだけで25±2℃充電し、終止を実測する。USBを外して対象温度へ移し、電池表面が目標±2℃に入り30分以上安定してから開始する。開始前OCVと累積サイクル数を記録する。
- 実マイクを16kHz以上、モノラルで連続動作させる。入力は無音8時間、規定音声/ノイズ4時間、無音4時間を含み、VADや一時停止を使わない。
- 電池側電流を十分な帯域で連続取得し、平均、最大、write/busy/startupピーク、積算mAhを算出する。
- 16時間中のreset、欠落sample、欠番file、未完了file、storage再初期化、録音停止を検出する。

合格条件: 5台全て16時間以上停止なし、平均4.4mA以下、16時間積算70.4mAh以下、観測ピーク110mA以下。16時間到達だけで電流条件を緩和しない。現状は未実測で保証しない。

## Gate D — 30時間分の累積暗号化保存

- Gate Dは30時間の電池連続動作試験ではない。各個体（Unit 1〜5）の同一電池・同一ストレージを使い、USBを外した電池駆動録音を3回行って合計30時間以上を蓄積する。各セッション間だけ録音を停止し、USBホストへ接続して同じ電池を充電する。電池交換、媒体交換、format、delete、取込み済みcleanupは禁止する。充電後はUSBを外して電源を再投入し、次の録音セッションを開始する。
- 現行ファームは電源専用USB給電でも充電できるが、Gate Dは録音中の外部給電を禁止し、各セッション間だけ録音を停止して充電する。これにより30時間保存と16時間連続電池動作を混同しない。16時間の無中断録音・無給電条件はGate Cで別に全5台確認する。
- 3セッションの16kHz以上モノラル実録音を合計30時間以上保存し、空き容量・クラスタ数・最大ファイル長を記録する。現候補の合成試験では963,999,744 byteの媒体で30時間後32,710,656 byteが残った（約3.39%）。20%余裕を満たしたとは扱わない。実媒体の必要予約量（未完了ファイル、回復処理、フォーマット差を含む）の数値と根拠は発注前に固定する未解決項目であり、この合成結果だけでGate Dを合格にしない。
- 全暗号ファイルを標準age実装で復号し、WAV構造、sample総数、時系列、file sequence、暗号化前後hashを照合する。
- 90%、95%、残量不足直前で正常終了し、既存完成fileを上書き・破壊しないことを確認する。
- 書込み中の電源断を注入し、最後の未完了fileだけが失われ、過去の完成fileが保存されることを確認する。

合格条件: 30時間分を全て復号・照合でき、平文音声をdevice上へ永続保存せず、容量不足と電源断で完成済みfileを失わない。

## Gate E — macOS・Windows・Linux

各OSの現行サポート版で、USB-C一端子から列挙、取込み、eject、再接続、復号、WAV再生を行う。USB-A変換ケーブル、C-Cケーブル、長短・太細の異なる少なくとも6本を使う。充電とデータの同時利用、suspend/resume、強制抜去を含める。

合格条件: 専用driver、無線、専用充電台なしで全OSが取り込める。記録中のstorage ownership、host export、eject後復帰が仕様通りで、破損・二重mount・録音漏れがない。

## Gate F — ケース・ネックレス

- 現候補mechanical-captured-carrier/a1mini-fit-kit/captured-carrier-fit-kit.3mfと同梱FIT-CHECK-INSTRUCTIONS.txtを使う。ケース下・キャリア・上の3部品で、PETG/0.4mmノズル/0.16mm層/6周壁/40%gyroid/tree supportのoffline sliceを確認済み。旧pebble-v5の向きは流用しない。材料lot、乾燥、slicer版、3MF hash、実際の配置・support除去・寸法を記録する。現3MFは寸法確認用であり、最終荷重試験の造形条件・蓋接合方法は未認定。
- 2mmと3mmの紐を使用し、引張、斜め引張、繰返し、摩耗、捻り、汗相当湿潤後の試験を行う。
- 装着用は連続した生コードや結び目だけを禁止し、首周り用途と離脱特性をメーカーが公開した単一の市販完成breakawayコードSKUへ固定する。型番、公称離脱範囲、lot、根拠資料hash、対象市場・年齢を含む製品リスク評価IDを記録する。未選定の現状は成人が管理下で使う試作だけとし、子供向け・睡眠中・機械作業中の使用を禁止する。
- ケース紐受けの試験案: 離脱claspを迂回した校正済み治具で50Nを10秒×3方向、15Nを10,000 cycle、紐を穴内で10,000 cycle摺動する。装着用コードへ50Nを要求して離脱機能を無効化しない。
- breakaway離脱荷重は各個体について新品、汗相当湿潤後、穴内10,000回摺動後の3状態で各10回以上測る。全測定がメーカー公称範囲と文書化した製品リスク評価の承認範囲内で、離脱後に危険な小部品、鋭利部、導電部露出がないことを確認する。適用市場と対象年齢を決める前に普遍的な荷重値を推定で設定しない。
- 1m落下を各面・角へ行い、ケース開き、白化、亀裂、電池損傷、USB位置ずれを確認する。
- 各個体でC-to-CとA-to-Cを含む6種ケーブルを使い、overmold幅・高さ、case干渉、connector shellの全挿入、奥当たり、抜差し荷重、横荷重を記録する。全挿入後に充電とデータ転送の両方を確認する。この6本への適合はUSB-C全製品への普遍適合を意味しない。

合格条件: 亀裂、白化進展、層間剥離、穴径の危険な摩耗、ケース開き、電池への荷重伝達、USB半挿しがない。各個体の6本すべてがcaseまたはovermoldと干渉せず全挿入でき、充電・データ転送に合格する。紐で吊ったとき横向き・裏返りが常態化しない。
