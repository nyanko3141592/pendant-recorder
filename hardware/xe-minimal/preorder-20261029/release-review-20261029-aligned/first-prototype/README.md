## 1. 成立見込みと手配判断

[部品別の計算値と感度](performance.json)では、室温の条件付き平均3.863mA、110mAhの70%使用可能という仮定で19.93時間、60%なら17.09時間。MCUは16MHzで常時Runの典型1.3mAを使用し、Sleep dutyによる有利な削減を入れない。周辺回路0.5mAとその他0.05mAは設計上の仮定。コア典型値を実ファームの保証値と呼ばない。

保存電流40mA/standby0.13mAは**採用部品自身のSD4wire/50MHz/25℃の値**であり、SPI4MHzへ適用できるとの保証はない。10秒周期の活動時間0.35秒を置く。このうちpayloadの線上時間は0.162344秒、残り0.187656秒をFAT・directory・busy等へ見込む。活動0.5秒なら約4.461mA/17.26時間、1秒なら約6.454mA/11.93時間（いずれも70%容量仮定）。0.35秒でも周辺回路が見積りより1mA多ければ約15.84時間。**16時間を狙う試作には合理性があるが、達成確率や最悪条件を証明したものではない。** 平均4.4mAは配分目標で、机上合格に置き換えない。

保存は10秒81,172byte、30時間payload876,657,600byte。FAT32/4KiB・3session端数・最大TMP/次ファイル等を含む必要data領域929,787,904byte。FAT等は別領域。合成媒体の現FatFs試験は既存証拠を利用し、実媒体容量は初回format時に読んで検査する。

[5台費用・購入先・数量](cost-and-supply.json)：部品と計画予備分約$375.34、全体予算**$695～1,045（換算仮定154円/USDで約10.7～16.1万円）**。正式見積ではない。全36電子部品行に単価を割り当て、工程、基板小径孔加算、書込み/format/治具/X-ray、税送料、5個の開発用電池、ケース材料、接着・絶縁材、紐を別枠で含めた。手持ち測定器・PC・プリンタを使用する想定。人件費と新規測定器は含まない。販売価格5,000円の達成は主張しない。

## 2. ケースと組立

[同版機構](../mechanical-first-prototype/)に編集用生成スクリプト、STEP/STL、5物体3MF、組立/分解STEP、分解図、組立手順を揃える。旧30.8mm角ケースは保全し、純正配線を除外した旧結果を現物の完成証拠には使わない。

今回の配線モデルは12/15/18mmを対象に、半径約2.89mmのU字通路と根元の直線部分を確保。被覆外径0.8mm・片側余裕0.2mm、線出口/嵌合位置は保守的な**設計仮定**でありメーカー保証値ではない。15±3mmを全て自由曲げ長さにしていない。赤い複数曲線は通路のサンプルで、全長の線を同時に入れるものではない。公式ヘッダの無効STEPは使用しない。

電池は面で底受けし、側方ガイドとキャリアで保持。キャリア裏へ総厚0.10mmの絶縁材を工場貼付し、最大パック上に0.4mmの成長予約を残す。膨張を許容する安全認定値ではない。蓋は6か所の深さ0.15mm接着ポケットと既存の位置決め/停止面を併用し、接着層によって蓋を持ち上げない。PETGと接着剤の実強度はダミーケースで試験する。
