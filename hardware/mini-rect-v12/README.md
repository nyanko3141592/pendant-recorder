# mini-rect-v12 — USB配置改善候補（発注不可）

v11の接続済み6層候補を比較原本として残し、外形を維持したままUSB経路を簡素化する。

- STM32U535の内蔵終端を利用し、調整用0Ω抵抗R8/R9を削除。実装点数は68→66。
- USBLC6-2P6をUSBコネクタ付近へ移動。TP1/TP3/R14/R6も移動。
- 回路ERC0、配置DRC0、明示的な回路図等価性検査0。未接続170の配置原本から配線中。
- 基板21×23×0.8mm、6層、In1/In4をGND面に確保。外観基準23×25×14mmを維持。

根拠：[ST STM32U535 DS14217 Rev5 Table136、p262](https://www.st.com/resource/en/datasheet/stm32u535ce.pdf)。終端内蔵の確認であり、差動インピーダンス・信号品質・保護性能を保証するものではない。

`order-status.json`が本候補の判定正本。v11模型は保存済みで、本候補の部品移動はまだ反映していない。再配線後のDRC/接続/USB経路/電源・基準面レビュー、ファーム統合、電池NTC調達、JLC部品照合、送料込み見積りが残る。注文・支払いはしない。
