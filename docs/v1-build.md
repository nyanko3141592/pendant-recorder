## 製作方針

個人製作は、小ロットの基板製造・部品実装を外注し、ケースへの組み付け、ファーム書込み、計測を自分で行う方式を設計上の前提とする。全端子の手はんだを前提にはしない。業者の対応可否、部品調達、費用はまだ確認していない。発注は未実施。

- 単一のカスタム基板に集約。開発モジュールの積み重ねを完成形にしない。
- 装着用v1はOmi Consumer相当の直径約25.5mm・厚さ約15mmを目標にする（[既存調査と出典](omi-reference.md)）。内部基板は直径22mmを初期の配置枠とし、USB-C・固定部・壁厚を含めて検証する。30mm角・4層版は電気検証用に限定する。
- 通常の貫通ビアで設計する。v1はHDI、ブラインドビア、ビアインパッド充填を必要とする密度を狙わない。
- 両面実装も候補に含め、電池との絶縁・膨張余裕を含めて高さを見積もる。片面実装への固定で本体を大型化しない。
- STM32U535RCT6 / LQFP64は電気検証用。装着用は22mm枠への配置成立を確認し、不成立なら小型パッケージを再選定する。BGAも実装業者の対応と通常ビアでの配線可否を確認して比較する。48ピンCBU6にはSDMMC端子がないため戻さない。
- 0402などの微小部品は実装業者が扱う。手作業の電池接続・書込み・測定箇所には作業空間を残す。密度より検証可能性を優先する箇所を明確にする。

## Omi相当の外形内で基板とケースを合わせる

無地の円形ケースを3Dプリントする方針。蓋の固定は小ネジを第一候補にし、固定部の体積も配置に含める。形状は配置と電池を決めてからSolidCraftで作る。首紐穴、本体USB-C、ボタン1個、録音・残量・状態の発光窓、マイク音孔を設ける。装飾、金属仕上げ、専用充電台、複雑なクリップはv1の作業に含めない。

USBのケーブル根元、ネジ、電池の絶縁・膨張余裕、マイクガスケット、LEDの遮光は必要な機構として残す。現存する26×12mmのSolidCraftモデルと外観4案は将来用の参考資料で、v1の製造データには使わない。

v1の外形目標は直径約25.5mm・厚さ約15mm。既存の26×12mmモデルは、より薄い案の未検証モデルでありOmiと同じ厚さではない。12gは引き続き軽量化目標。サイズの成立は未確認で、実配置と電池の実寸から検証する。48時間録音、USB-Cの充電のみ／同期、全インジケーターは引き続き検証対象。

## 次に確定する順番

1. 微小パッケージの部品調達・小ロット実装可否を照会できるBOMにする。USB-C、電池、Q1、D2、水晶を実型番で選定する。
2. 全フットプリントをメーカー端子図と照合し、装着用22mm円形枠で実配置する。電気検証用30mm角とは分ける。USB・音孔・LED・ボタン・SWDと電流測定パッドの位置を先に確保する。
3. 電源経路と録音経路の試作検証を進め、実装レビュー・配線・DRCを完了してから基板発注資料を出す。ERC合格だけでは発注しない。
4. 電源・充電・USB挿抜・SD所有権の切替を確認し、実際の電池で48時間の録音を検証する。失敗時は電池容量や回路を見直す。
5. Omi相当の外形内で成立した基板・電池に合わせて簡易ケースを作り、装着と音質を確認する。外観の磨き込みはその後。
