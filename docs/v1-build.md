# v1 — 個人製作と基板密度を優先

2026-10-24のユーザー指示: 「個人で作れる範囲まで」「v1なのでデザインは一旦おいておいてシンプルで」「回路的に密度高ければいい」。外観4案の選定・仕上げは保留する。

## 製作方針

個人製作は、小ロットの基板製造・部品実装を外注し、ケースへの組み付け、ファーム書込み、計測を自分で行う方式を設計上の前提とする。全端子の手はんだを前提にはしない。業者の対応可否、部品調達、費用はまだ確認していない。発注は未実施。

- 単一のカスタム基板に集約。開発モジュールの積み重ねを完成形にしない。
- まず30mm角・4層の配置検討から開始し、実部品・配線・検査パッドが成立する範囲で縮める。30mm角は配置未検証の初期枠で、確定寸法ではない。
- 通常の貫通ビアで設計する。v1はHDI、ブラインドビア、ビアインパッド充填を必要とする密度を狙わない。
- 実装は片面を優先。裏面は電池と絶縁・膨張余裕に使う。片面で成立しない場合は無理に縮めず、両面実装の費用と組立空間を比較する。
- STM32U535RCT6 / LQFP64を維持。22mm円形化のためのMCU BGA化はv1の必須工程にしない。
- 0402などの微小部品は実装業者が扱う。手作業の電池接続・書込み・測定箇所には作業空間を残す。密度より検証可能性を優先する箇所を明確にする。

## ケースは基板に合わせる

無地の角丸ケースとネジ留めの蓋を3Dプリントする方針。形状は配置と電池を決めてからSolidCraftで作る。首紐穴、本体USB-C、ボタン1個、録音・残量・状態の発光窓、マイク音孔を設ける。装飾、金属仕上げ、専用充電台、複雑なクリップはv1の作業に含めない。

USBのケーブル根元、ネジ、電池の絶縁・膨張余裕、マイクガスケット、LEDの遮光は必要な機構として残す。現存する26×12mmのSolidCraftモデルと外観4案は将来用の参考資料で、v1の製造データには使わない。

従来の直径26mm・厚さ12mm・12gは将来の小型化目標として残す。v1の合否条件にはせず、基板配置と電池の実寸から外形・重量を報告する。16時間録音、USB-Cの充電のみ／同期、全インジケーターは引き続き検証対象。

## 次に確定する順番

1. 微小パッケージの部品調達・小ロット実装可否を照会できるBOMにする。USB-C、電池、Q1、D2、水晶を実型番で選定する。
2. 全フットプリントをメーカー端子図と照合し、30mm角から実配置する。USB・音孔・LED・ボタン・SWDと電流測定パッドの位置を先に確保する。
3. 電源経路と録音経路の試作検証を進め、実装レビュー・配線・DRCを完了してから基板発注資料を出す。ERC合格だけでは発注しない。
4. 電源・充電・USB挿抜・SD所有権の切替を確認し、実際の電池で16時間の録音を検証する。失敗時は電池容量や回路を見直す。
5. 成立した基板・電池に合わせて簡易ケースを作り、装着と音質を確認する。外観の磨き込みはその後。
