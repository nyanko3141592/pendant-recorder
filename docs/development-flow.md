# 初号試作の進め方

2026-10-29のユーザー指示を反映。正本は[requirements.md](requirements.md)。今回は費用を抑えた小型の1回目の試作を作り、実際に使って評価する。実機・電流ログはまだない。

## 判断基準

基本安全対策を前提に、使い勝手（特に電池持ち）→小型化→初回費用の順で判断する。固定DTP401525-XE、27.5mm角基板、最大4層、通常through via、16時間録音、30時間以上保存を維持する。

根拠のある理論見積りで性能達成を見込めれば試作判断へ進める。仮定と未実測を明示し、完成品の保証と混同しない。4.4mAは配分目標で、実測ログがないことを設計作業の停止条件にしない。現見積りの未知量を合格に変えるものでもない。

## 設計を進めた3段階（現状）

1. 採用構成・条件付き電流見積り・5台費用を集約。C30を同定格在庫品へ置換。U1/U12/J1は通常Pre-order、入庫後の基板注文を選ぶ。
2. 現ケースから配線bayと接着ポケット、絶縁材を具体化。約30.8×37.5×14.2mm。同版STEP/STL/5物体3MFと組立手順、明示した配線仮定を確認。
3. 基板/回路/CAMとファームの未変更hash、BOM置換、CAD・slice・キット対応を検証しGitへ納品。書込み済み製品の完成と物理評価は別。

入口は[初号試作設計](../hardware/xe-minimal/preorder-20261029/release-review-20261029-aligned/first-prototype/README.md)。現在の残件は実行可能な通電・書込み・通常工場工程・部品入庫・現物fit/性能評価へ分けてある。

## 試作後に評価すること

電池持ちと録音継続、実媒体30時間保存、USB取込み・充電、温度、音質、装着性、実ケーブル、ケース接合と紐の強度。未実測であることは明示するが、これら全ての実測合格を初回基板発注より先に要求しない。量産の工程認定・長期供給最適化は後段とする。
