XE固定電池・5台試作試験計画（未実施）

ID 設計・個体識別 / 各5台
前提: 回路・ファームの検証開始条件
方法: PCB版、部品実装差分、FWバイナリhash、設定、電池SKU/ロット、ケース版、測定器と校正情報を記録。BORをリセット後に読み戻す。診断用起動試験ではHSI選択、MSIS停止、録音開始後のMSIKを確認する。電池持ち本試験はデバッガを外した通常ビルドで行う。
合否: 対象設計と一致。BOR4読戻しを保存。試験用鍵/VID/PIDのビルドを製品リリースと扱わない。
結果: 未実施

FIT 電池無加工組立 / 各5台
前提: 電池接続前の極性・電源設計確認
方法: assembly-validation-plan-ja.txtに沿って、純正プラグ・線を含む挿入過程と閉鎖前後を記録。
合否: はんだ付け・線加工・端子交換なし。完全嵌合、挟み込みなし、指定曲げ条件内。ケース閉鎖が電池を圧迫しない。未確定のプラグ寸法・曲げ条件は合格扱いしない。
結果: 未実施

POWER 電源・保護の基礎試験 / 各5台
前提: ID
方法: まず電池エミュレータで電圧掃引と負荷変動を試す。起動/録音/保存/USB挿抜/充電時の電池電流・各電源・制御信号を測る。Q6/Q7は専用bench-planも実施。
合否: 部品と電池の公開定格内。110mA連続放電制限に対し、ピークを独自の許容値で免除しない。過渡応答、逆流、停止・再起動を評価。
結果: 未実施

TEMP 充電・温度監視 / 各5台
前提: POWER; 閾値一覧を公開仕様と現回路から試験前に固定
方法: xe-film-temperature-resistance-stimuli.jsonの現基板基準を使い、設計検証済み電源でNTC正常/開放/短絡と境界抵抗を模擬。実電池では接触構造・電池表面温度・充電電流/電圧/終止を記録する。
合否: 公開電池仕様の電圧・電流・温度範囲を公差込みで満たす。異常時充電停止と復帰条件を満たす。センサー接触の熱遅れが未評価なら未合格。
結果: 未実施

R16 無給電16時間連続録音 / 各5台
前提: FIT,POWER,TEMP; 供試電池の状態と周囲条件を記録
方法: xe-r16-evidence-protocol.jsonの時刻照合と証拠保存条件を使用する。採用充電条件で充電しUSBを外す。外部時刻基準つき音源と予定した無音区間を交互に与え、16時間以上実録音。電流/電圧/温度を記録し、停止後に全ファイルを取り込んで復号・検証する。
合否: 充電なし実時間57600秒以上、16kHz以上モノラル、無音も同じ時間軸で保存。欠落/重複/破損なし。ファイル総時間だけで連続性を判定せず外部時刻と照合する。平均電流計算だけでは合格にしない。
結果: 未実施

S36 36時間分の累積暗号化保存 / 最低1台で同一電池・同一媒体の3セッション、残4台は個体保存・復号確認
前提: POWER,TEMP; 36hは累積容量試験であり電池連続時間の証明ではない
方法: 実ストレージにUSBを外した電池駆動録音を3セッション蓄積する。セッション間だけ録音を停止してUSBホスト接続で同じ電池を充電し、電池・媒体を交換せず、format/delete/cleanupせずに再起動する。合計36時間以上になった後、全ファイルを復号・検証する。現行安全ポリシーと矛盾する充電専用給電中の録音は行わない。
合否: 3セッション合計129600秒以上が同じ媒体に共存し既存ファイルを上書きしない。録音中USB給電0秒、電池交換0回、セッション間充電2回。保存領域に平文音声を出力しない構成をコードと媒体の両面で確認。媒体の文字列検索だけを暗号化の証明にしない。
結果: 未実施

HOST 3OSで取込み・復号 / macOS/Windows/Linuxで各1台以上、全5台にUSB認識確認
前提: ID,POWER; 実USBと対象OSが必要
方法: 同一既知音声を各OSで取込み、秘密鍵による復号、整合性、保存先権限、重複取込み、再接続を確認。
合否: 全OSで音声を回収でき、復号内容が一致。失敗時は原本保持。秘密鍵を本体へ書き込まない。OSとツール版を記録。
結果: 未実施

FAULT 電源断・USB異常・容量上限 / 代表1台で各状態、残4台は正常停止/復帰
前提: POWER,HOST
方法: 録音保存中の制御された電源断、USB取込み途中抜去、容量上限、低電圧停止/再開抑止を試す。破損試験は専用コピーで行う。
合否: 確定済み区間を回収。不完全区間を検出し、未取込みデータを黙って削除・上書きしない。MSC中に本体が同じ媒体を書き換えない。
結果: 未実施

CASE 印刷・閉鎖・使用時形状 / 各5台
前提: FIT; 固定電池と16時間録音を満たす条件下で完成品を最小化。30×32×15mmは絶対上限ではない
方法: PLA印刷寸法、仕切り板の厚さ/反り、接着後のUSB挿抜、音道、温度接触、完成外形を測る。保持強度の負荷条件を試験前に固定。
合否: 固定電池と16時間録音を優先して必要な大型化を許容し、完成外形を測定してOmi参照寸法と比較する。配線/電池に締付荷重を加えない。最新CADに対応する仕切り板の絶縁と保持が使用条件で維持。試験負荷が未定義なら強度は未合格。
結果: 未実施
