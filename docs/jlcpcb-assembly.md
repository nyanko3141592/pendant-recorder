# JLCPCBで基板製造から実装まで依頼する方針

2026-10-24。ユーザーがJLCPCBの利用を許可。基板だけを購入して微小部品を自分ではんだ付けする設計ではなく、**基板上の部品を実装して納品してもらう前提**で部品・パッケージを選ぶ。電池接続、ケース組立、ファーム書込み、実機検証は自分で行う。

## 製造方法

- 高密度の両面実装を想定し、**Standard PCBA**を第一候補とする。公式能力表ではEconomicは片面、Standardは両面対応。
- 小さな製品基板は製造用の捨て板・パネルに載せる。公式Standard最小寸法70×70mmは製造時の条件として処理し、本体を70mmへ拡大しない。パネル構成、分割位置、エッジ余白、フィデューシャル、搬送穴はJLC側レビューで確定する。
- 4層・通常の貫通ビアを基本にする。板厚・表面処理は小型パッケージと反りを含めて決定。最安プランに合わせるための部品の手実装は前提にしない。
- 現在のWCSP/DSBGA/LGAを含むBOM全体が受理可能かは未確認。JLCの一般的な対応パッケージに載っているだけで、その品番・フットプリントの実装を承認済みとしない。

## 公開例と、その証拠の範囲

OMOTE-Communityの公式ハードウェアWikiは、Standard / Both Sides、捨て板、Gerber・BOM・CPL、部品選択・配置確認までのJLCPCB発注手順と製造ファイルを公開している。**両面実装まで依頼する公開ワークフローの前例**として参照する。

ただしOMOTEは別回路であり、本機のSTM32U535、T5838、BQ25101、TXS0104E、SD NANDが同一パッケージで実装・動作確認された証拠ではない。今回確認したWikiだけから納品済み実機・量産歩留まりまで立証したとは扱わない。OmiについてもJLCPCBで実装されたと推測しない。

## 部品採用の条件

1. メーカー型番・パッケージ・ピン番号とKiCadフットプリントを一致させる。
2. JLCの実装部品番号、実装用在庫、必要数、最低調達数、拡張部品費を確認する。LCSCの販売在庫だけで実装可能と判定しない。
3. 入手できない部品は機能・消費電力・寸法を確認して代替する。微小ICを未実装で受け取り後から手実装する解決にはしない。個別調達サービスを使う場合も費用・受入確認後に採用する。
4. T5838の底面音孔とペースト/リフロー条件、WCSPのパッド・ステンシル、SD NANDの向き、USB-Cの固定脚、両面部品の工程を照合する。
5. Gerber・ドリル・実装BOM・CPL（面、回転、座標）・組立図を一致させ、JLCの部品マッチング・配置レビュー・見積りで受理を確認して初めて「この基板は実装まで依頼できる」とする。

BOM公開やERC合格は、この受理確認の代替ではない。実装前例が必要な部品は同品番・同パッケージの根拠を別途残し、未確認なら未確認とする。

## 現状

回路ドラフトの主要IC・微小パッケージについて、全品番の実装可否・在庫照合はこれから。PCB配置・配線・CPLは未作成。公開例と公式製造条件を確認した段階で、発注・部品予約・アップロードは行っていない。電池は国内調達のDTP401525(PHR)を第一候補に保ち、JLCのリフロー工程には投入しない。
