# v1の録音目標: 連続24時間

ユーザー最新指示「24時間達成を目標で」により、48時間から**連続24時間録音**へ変更。無音時を含めて保存し、音声検知による録音省略で時間を延ばした数値にはしない。旧48時間の比較はtwo-day-runtime.mdに履歴として残す。

## 電池と消費電流の条件

使用可能容量を公称の70%と仮定する従来の設計予算を継承。劣化・温度・停止電圧などを含む仮定であり保証値ではない。

| 公称容量 | 24時間に必要な平均電流上限 | 平均2.0mA時の計算上の時間 |
|---|---:|---:|
| 80mAh | 2.33mA | 28時間 |
| 100mAh | 2.92mA | 35時間 |
| 150mAh | 4.38mA | 52.5時間 |

計算: 容量×0.70÷電池端平均電流。平均2.0mA以下の省電力目標は維持し、**100mAh級を最初の配置候補、80〜150mAhを比較範囲**とする。80/100mAhは容量予算で、調達可能な実型番・外形を選定済みではない。既存150mAh候補も比較基準として残す。全LED・SD内部busy・保護回路を含む実測で決定する。

24時間のデータ本体はADPCM約0.69GB、PCM約2.76GB。付加分と空き容量を確認したうえで4GBを維持し、標準はADPCM、PCMは比較用に切替可能とする。自動削除は行わない。

## サイズと検証

[密度検討](density-study.md)の24×24×14mm角丸外形・21×21mm両面基板を初期枠として維持する。円形は必須ではない。容量を減らせば必ず外形を縮められるとは限らず、実パックの保護回路・配線・USB-Cと合わせて配置する。

合否は、実際の電池で24時間連続記録し、終了まで音声ファイルが読めること。低残量表示、低電圧時のファイル確定、USB-Cの充電のみ／MSC切替も検証する。現在は仕様更新のみで、24時間達成・基板配置は未検証。
