# v1の録音目標: 連続24時間

> 最新優先（2026-10-24）: [小ささ最優先・16時間以上・USB-C・無線任意](decisions/0006-size-first-16h.md)。以下の24h必須/無線搭載必須は旧条件。圧縮音声36h保存、暗号化、有線取出し、無はんだ組立は維持。新MCU/電池/外形は未確定。

> Rev A1更新: [実フットプリントでの配置検討と未解決項目](../hardware/rev-a/layout-review.md)。基板20×34mmは未配線の検討値。充電は6.19kΩで公称21.8mAへ変更。旧50mA設定や外形枠よりこの更新を優先する。

ユーザー最新指示「24時間達成を目標で」により、48時間から**連続24時間録音**へ変更。無音時を含めて保存し、音声検知による録音省略で時間を延ばした数値にはしない。旧48時間の比較はtwo-day-runtime.mdに履歴として残す。

## 電池と消費電流の条件

使用可能容量を公称の70%と仮定する従来の設計予算を継承。劣化・温度・停止電圧などを含む仮定であり保証値ではない。

| 公称容量 | 24時間に必要な平均電流上限 | 平均2.0mA時の計算上の時間 |
|---|---:|---:|
| 80mAh | 2.33mA | 28時間 |
| 100mAh | 2.92mA | 35時間 |
| **110mAh（第一候補）** | **3.21mA** | **38.5時間** |
| 150mAh | 4.38mA | 52.5時間 |

計算: 容量×0.70÷電池端平均電流。平均2.0mA以下の省電力目標は維持し、[調達調査](battery-sourcing.md)により**DTP401525(PHR) 110mAhを第一候補**とする。80/100mAhは容量予算で、調達可能な実型番・外形を選定済みではない。既存150mAh候補も比較基準として残す。全LED・SD内部busy・保護回路を含む実測で決定する。

24時間のデータ本体はADPCM約0.69GB、PCM約2.76GB。付加分と空き容量を確認したうえで4GBを維持し、標準はADPCM、PCMは比較用に切替可能とする。自動削除は行わない。

## サイズと検証

外形・基板の固定寸法を解除し、[既製パック優先の寸法予算](battery-sourcing.md)へ更新する。円形は必須ではない。容量を減らせば必ず外形を縮められるとは限らず、実パックの保護回路・配線・USB-Cと合わせて配置する。

合否は、実際の電池で24時間連続記録し、終了まで音声ファイルが読めること。低残量表示、低電圧時のファイル確定、USB-Cの充電のみ／MSC切替も検証する。現在は仕様更新のみで、24時間達成・基板配置は未検証。
