# 小型USBレコーダーの製品要件

2026年10月29日更新。この文書を要件の正本とする。過去の追記、候補比較、未送信問い合わせ草案と矛盾する場合は、この文書を優先する。要件の確定と設計・実機の合格は別であり、現在の設計は未合格。

## 2026年10月29日に確定した設計範囲

- **基板外形27.5×27.5mmを維持する。** 27.5mmはケース外形上限ではない。ケースは基板・固定電池・純正配線・必要な保護と組立余裕を収めた完成状態で最小化する。
- **JLCPCBで基板製造・全電子部品実装を一括発注できることを条件とし、調達性を重視する。** カタログ登録、在庫、対応実装方式を区別し、持込み部品・手はんだ・個別交渉を前提にしない。未確認の在庫や工程を発注可能と扱わない。
- **小型化のために基板層数を増やさない。** 現4層を上限に、同じ基板外形の中で素子配置・実装面・電池との重なりを再検討する。HDI、ブラインドビア、filled/capped via等の追加費用で小型化を成立させない。調達・実装費と配線成立性を同時に評価する。
- **手戻りと組立の手間を減らす。** 寸法だけを追う局所修正を繰り返さず、部品と製造条件を確認し、ケース案は固定した内部配置に対する少数比較で選ぶ。
- **電池の衝撃保護をケースの設計条件に含める。** 保持、絶縁、配線挟み込み防止、膨張余裕を確保し、セルへ点荷重を掛けない。CAD干渉0だけで落下・衝撃耐性を合格としない。
- 実際の注文・支払い・製造データupload・業者連絡・量産実行は行わない。発注判断できる設計完成を目指す。

## 初号試作の目的と優先順位（2026年10月29日・最新ユーザー指示）

今回は1回目の試作。ある程度費用を抑えて小型の実物を作り、日常で使って評価する。量産認定を今回の完成条件にしない。実機も測定ログもまだない。

基本的な安全対策（電池保護、充電制御、温度監視、絶縁、配線挟み込み防止）を設計の前提とし、次の順で判断する。

1. **使い勝手** — 電池持ち、連続録音の安定性、装着性、USB取込み・充電を優先する。固定110mAhで16時間録音、30時間以上保存を目標として維持する。
2. **小型化** — 使い勝手を守ったうえで最も重視する設計目標。基板27.5mm角・最大4層・通常through viaを維持し、電池・純正配線・保持・絶縁を含む完成品を最小化する。
3. **初回試作費** — 通常の調達・実装・基板工程を使い、必要以上の層数、特殊via、部品、組立工程を増やさない。量産向けの認定や工程の作り込みを先行させない。
4. **組立の容易さと将来の量産性** — JLCPCB一括実装、購入者作業は電池・ケース・紐のみの方針を維持する。長期供給や量産試験の最適化は、初号試作の評価後に進める。

性能は根拠のある理論見積りで目標達成を見込めれば試作判断へ進める。仮定、典型値、保証値、余裕、未評価範囲を明記し、理論見込みを実測合格や保証と呼ばない。平均4.4mA／70.4mAhは設計配分目標であり、実測ログがないこと自体を作業停止条件にしない。現在の電力配分は未完成で、ユーザーの許容変更だけを根拠に「理論成立」と書き換えない。

## 作業順序

1. 現構成の電力・容量見積りをまとめ、16時間録音と30時間保存を狙える根拠・仮定・余裕を示す。測定結果を要求して設計作業を止めない。
2. 基本安全回路、部品調達、製造寸法、実装方向を初号試作に必要な範囲で確認する。
3. 固定基板・電池・純正配線が収まる小型ケースと接合を仕上げる。新たな外観案や細切れ配線探索を繰り返さない。
4. 同じ版の回路・BOM・PCB・製造データ・ファーム・実寸キット・組立手順・費用見積りを揃え、発注前の不足と試作後の評価を分ける。
5. 試作後に電池持ち、録音、取込み、温度、装着性、ケース・紐・USBの実用性を評価し、次版へ反映する。

注文・支払い・製造データupload・業者連絡・実印刷は禁止のまま。Gitへのcommit/pushはユーザーの別途指示により許可されており、この製造行為の禁止には含めない。

## 判断規則

- 下位項目のために上位項目を犠牲にしない。複数案は上記の順で比較して一案を選ぶ。
- 根拠がなければ「未確認」とし、計算値、シミュレーション、非実機テスト、実測を区別する。未実測の16時間動作を保証しない。
- 調達可能性は正確な型番、在庫、実装可否まで確認する。
- 局所CAD修正を繰り返さず、回路・BOM・製造方式と機構をまとまった単位で判断する。
- 上位条件を両立できない場合だけ、根拠と緩和案を示してユーザーへ確認する。
- 注文、支払い、製造データのアップロード、業者への連絡は行わない。

## 製品条件

1. 販売者は回路（書込み・検査済みの実装基板）とケースを販売する。電池は販売・同梱しない。
2. ユーザーは回路・ケースと、指定の市販電池をそれぞれ購入し、自分で組み立てる。
3. 電池は調達性の高い標準販売品に限定する。日本の個人が通常通販で少量購入でき、メーカーへの問い合わせ・特注・購入交渉を必要としない。一時的な在庫や単発のフリマ出品だけで調達性を満たしたとしない。
4. 電池・配線・コネクター・ケース・本体固定部を組み込んだ完成状態を最小化する。Omiサイズ以下を目標とするが、固定電池と16時間録音を優先し、必要な大型化を許容する。基板だけの寸法では判定しない。
5. 指定電池で充電なしに連続16時間以上録音できること。無音を飛ばす間欠録音や外部給電で代替しない。

固定電池と16時間録音をサイズより優先する。必要な大型化は許容されるが、容量・録音時間を変更したり、購入者に調達交渉や配線加工を要求したりして成立扱いにしない。設計計算と実測による合格を区別する。

## 販売するものと購入者が用意するもの

販売するのは、ファーム書込み・検査済みの実装済み基板、完成ケース、必要な固定・絶縁・温度センサー接触部材、組立説明書。電池は販売・同梱・輸入代行・加工して提供しない。

購入者は、互換リストに掲載した市販の完成電池と安全離脱式の完成ネックレスコードを販売店から直接購入する。電池をコネクターへ挿し、指定位置へ収め、ケースを閉じ、完成コードを穴へ通せば使えること。はんだ付け、圧着、線の切断・延長、紐端末加工、コネクター交換、保護回路追加、電池パックの分解、ファーム初回書込みを購入者に要求しない。初回試作はユーザーの了承により接着剤によるケース閉鎖を許容する。接着するのはケースの合わせ面とし、電池や配線を接着固定しない。接着仕様と組立手順は別途検証する。

USB-CケーブルとPCは購入者が用意する。PC側ツールのインストールと初回の鍵登録は必要。電池取り付け手順とPC設定手順を分けて説明する。

## 電池の採用条件

以下の全条件を満たす標準販売品を、最低1型番確定してから基板・ケースを確定する。代替品は個別に検証して追加する。

1. 日本の個人が通常の通販手続きで少量購入できる。見積依頼、メーカーへの問い合わせ、法人契約、特注ハーネス、購入者自身の輸入交渉を必要としない。1個または小口パックで買えること。必要個数と余剰分を費用表示する。
2. 保護回路・絶縁・リード線・完成コネクターを備える。裸セルやタブだけの電池は対象外。
3. 公開資料で、メーカー型番・販売SKU、パック最大寸法、配線長とコネクター外形、嵌合する基板側品番、極性を特定できる。容量や「JST」「1.25mm」だけの一致で互換としない。
4. 公開仕様で、充電上限電圧、充電電流・終止条件、連続放電電流、温度範囲を照合できる。電流の単位誤記や不明点を推定で補って採用しない。
5. 出荷状態の線を切らずに、配線の曲げ、コネクター嵌合、絶縁、保持、必要な膨張余裕まで含めてケースに収まる。
6. 充電回路・電源・温度監視をその電池に合わせる。2線電池でも本体側の温度監視を省略せず、購入者がセンサー配線を加工せずに組める接触構造を備える。
7. 製品説明に販売リンク、完全な品番、極性図、取り付け写真、非対応品の見分け方を載せる。販売終了時に曖昧な類似電池を代用品として案内しない。

問い合わせをしなければ条件を確認できない電池は、その時点で採用対象から外す。問い合わせ草案の作成・送信・返信待ちを開発工程に入れない。開発側の寸法・動作検証は必要だが、購入者には仕様調査や電気測定を要求しない。

最新ユーザー指示により容量は110mAhで固定。国内での通常購入のしやすさからDTP401525-XEを採用し、その後に回路を設計する。マルツのDTP401525(EZ3)は同電池と相手コネクターのセットとして購入可能。基板側コネクターは販売者が実装し、購入者のはんだ付けは不要。電池選定を再び未確定扱いに戻さない。

## 機能と外形

| 項目 | 確定する要件 |
| --- | --- |
| 用途 | 小さく身につけて単体録音し、USBで自分のPCへ取り出す |
| サイズ | 固定電池で16時間録音できる完成品を最小化する。Omiサイズ以下を目標とし、必要なサイズ増加は許容する。旧25×25×15mmや30×32×15mmを絶対上限にしない。参照するOmi製品を明示して同縮尺比較する。円形は必須にせず角丸四角を優先 |
| 寸法の範囲 | 電池・配線・蓋・固定部・本体の紐通しを含む。柔軟な首紐と使用時のUSBケーブルは除く。突出部を除外して小さく表示しない |
| 録音 | 16kHz以上・モノラルで、充電なし連続16時間以上。無音も記録し、間欠録音で時間を稼がない |
| 保存 | 1GB管理型NANDに圧縮音声30時間以上。電池持ち16時間とは独立した要件。形式とファイル管理領域を含めて容量を確保する |
| USB | 本体のUSB-C一端子で充電・有線データ転送。専用充電台不要 |
| PC同期 | データ接続成立後に区間確定・録音停止・ファイルシステム解放を行い、MSCで公開。PCツールが自動取込み・復号・検証する。MSC中は本体から保存領域へアクセスしない |
| 充電だけの接続 | 録音状態を維持。USB電流制限・温度異常・電圧異常時は保護動作を優先する |
| 録音復帰 | 正常取り外し・切断後に保存領域を再取得して同期前の録音状態へ戻す。異常抜去は整合性を確認して復旧 |
| 対応PC | macOS・Windows・Linux。復号後は一般的なPCM16 WAVで保存 |
| 紛失保護 | 本体には公開鍵のみを保存。平文音声を本体ストレージへ書かない。秘密鍵はPC側で管理 |
| 鍵の量産登録 | 工場は全個体共通ファームを書込み、購入者公開鍵は初回USB HIDでwrite-once登録。未登録では録音しない |
| USB録音ストレージ | MSC公開中は常にread-only。PCからのWRITE/formatを拒否し、鍵登録に流用しない |
| 電源断・満杯 | 短い標準形式の独立区間を逐次確定。確定済み区間を回収し、不完全区間は検出・保全。未同期録音を上書きしない |
| 削除 | PC保存・復号・完全性・永続化を検証できた一致録音だけを既定の同期処理で削除。失敗時は原本を残す |
| 表示・操作 | 電池残量表示を中心に最小限の表示と操作。画面や多数の専用LEDを必須にしない。満杯・異常を判別できること |
| 無線 | Bluetooth・Wi-Fiを搭載しない |
| 装着 | 角・辺を丸め、首掛けできる。紐・衣服でマイクを塞がず、肌当たりと衣擦れを評価する |

Omiサイズに収まらない場合も、固定電池と16時間録音を優先し、保存部品・回路構成・配置を見直して完成品を最小化する。必要なサイズ増加は今回のユーザー指示で許容された。16時間、30時間、無加工組立など、サイズ以外の条件変更には引き続き相談が必要。

## 価格と費用の表示

販売価格目標は電池を含まない本体キットで税込5,000円以下。これは今回の電池別売り方針に合わせた設計上の価格対象で、達成済みではない。指定電池・その購入送料を加えた利用開始総額を必ず併記し、「全部込み5,000円」と表示しない。ケーブル等の追加購入が必要なら別記する。

5台試作費は販売価格と分け、基板製造・部品・実装・ケース・組立部材・開発検証用の電池5台分・送料・税・必要治具を集計する。電池を製品として販売しないことと、開発検証用電池の費用を省くことは別。未確定の費用はゼロ扱いしない。

発注前には公開仕様との整合、部品調達性、回路/配線チェック、収納・組立検証、費用と未解決リスクを確認する。16時間実動作、実媒体30時間保存、USB実機動作、温度・電源断・落下・装着・音質は試作後の合格条件。未実測の合格を主張しない。

回路・機構・ファーム・最小ホストツールは公開する。独自成果物MIT、第三者ライセンスは保持。文字起こし・要約・クラウド・サブスク・専用スマホアプリは対象外。

## 現在の候補の扱い

採用電池はDTP401525-XE（110mAh）で確定。選定記録は[sourcing/battery-first-selection.json](sourcing/battery-first-selection.json)。完成パック最大15.5×27×4.2mm、配線15±3mmを設計入力とする。現採用の初号試作候補はb3cdfc…の4層27.5mm角・両面実装基板、C30=C501830、配線bay付きmechanical-first-prototype（約30.8×37.5×14.2mm）。Case V3と旧30.8mm角captured-carrierは履歴。初号試作は一般4層の非認定インピーダンス基板として評価し、部品入庫と注文時製造確認を実行条件とする。旧6層版を製造に使わない。ケース縮小案は別保存し、採用と実機合格を区別する。旧V15、24×27mm、外付けTH1、旧ケース、旧CAMは履歴であり製造へ使用しない。16時間、30時間、安全性、ケース強度は実機未測定で、候補寸法や非実機試験を合格証拠にしない。未送信の問い合わせ文は履歴として保存し、送信しない。

旧要件は[履歴](history/requirements-before-user-battery-20261026.md)へ移した。履歴中の明示操作のみの同期、無線任意、電池同梱価格、30×32mm完成案等を現在の要件へ戻さない。

最新の設計ゴールと工程は[design-goal.json](../hardware/xe-minimal/design-goal.json)に記録する。既存回路やケース寸法を固定せず、電源・保存方式から再検討する。

## 完成時の3DモデルとOmi比較（2026-10-26追加）

完成時には、編集可能なケースCADに加えて、完成品の外観3Dモデルと内部・分解組立モデルを提出する。内部モデルには基板、指定電池、出荷時の配線、コネクター、絶縁、保持部、ケースと組立余裕を含める。製造用形状と説明用の簡略形状を区別する。

Omiとのサイズ比較は同一縮尺の3D配置と正面・側面・重ね合わせ図で示し、完成外形・厚さ・突出部を含む寸法を併記する。参照したOmiの製品・版と寸法の出典を明示し、公開CADの版や組立状態が確定できない場合はその不確かさを表示する。独自の推定外形を実製品の確定寸法として使わない。

比較モデルは設計完成版と対応させる。途中のモデルは未完成案と明示し、収納や16時間動作が成立した証拠として扱わない。

## 自宅でのケース試作条件

ユーザー所有のBambu Lab A1 miniとノズル径0.4mmを使用する。初期のPLA指定は履歴とし、現行case v4は紐受けの疲労・摩耗・耐熱と積層方向を優先してBambu PETG Basic、0.16mm layer、6 walls、40% gyroid、support有効を正本条件とする。lowerはCAD X＝穴軸をプリンタbuild Zへ回転して平行にし、主な紐荷重が層間剥離だけへ掛からない向きで印刷する。外形は全辺を丸め、初回試作では接着剤止めを許容する。印刷用STL/3MF、編集可能なケースCAD、印刷方向・設定、組立手順を同じcase v4版で用意する。スライス成功は印刷、嵌合、50N proof、15N/10,000-cycle疲労、紐摩耗、安全離脱、汗、落下、USB嵌合の合格を意味しない。

2026-10-29確認：ユーザー回答「30時間以上でよい」により累積暗号化保存の最低要件を30時間へ統一する。旧design-goal.jsonの36時間は失効。16時間連続電池録音は別要件として維持する。
