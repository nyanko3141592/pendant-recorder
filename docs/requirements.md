# 要件（2026-10-24 確定）

## ユーザー要件（Naoki確定・変更不可）
1. **有線通信のみ**: BLE・Wi-Fi・NFCなど無線は一切載せない（無線チップ・アンテナも不要）
2. **充電・同期をUSB-C 1本で**: 挿すと充電され、同時にMacからUSBドライブ（MSC）として見える
3. **1日使える**: 起きている間 16時間の録音（目標）
4. **できるだけコンパクト**: ペンダント型。カスタム基板（回路から設計）OK

## 導出仕様
| 項目 | 仕様 | 根拠 |
|---|---|---|
| 音声 | 16kHz / 16bit相当 / モノラル | 日本語の文字起こし（kotoba-whisper）に十分。Omiも16kHz |
| 保存形式 | IMA-ADPCM WAV（4bit, 64kbps）を本命、PCM WAVを切替可 | 下記「容量」。ffmpeg/ほぼ全ツールで読める |
| 容量 | 16h×PCM=約1.84GB、ADPCM=約0.46GB。**4GB以上**の内蔵ストレージ | 16000×2B×57600s。ADPCMは1/4 |
| ファイル | FAT32/exFAT上の通常ファイル、5分ごとに分割 `REC/YYYYMMDD/HHMMSS.wav` | MSCでそのままMacから見える |
| 平均電流 | 録音中 **3mA以下**（目標1.5mA） | 電池100mAh級に収めるため（custom-pcb.md §3） |
| 電池 | 1S LiPo 80〜150mAh | 16h×3mA=48mAh＋劣化・低温マージン |
| 充電 | USB 5V、100〜250mA、満充電 1時間程度 | BQ25101（最大250mA） |
| 同期 | USB 2.0 FS MSC。1日分を**10分以内**で吸い出し（ADPCM時） | 実効~1MB/s見込み（推定） |
| 時刻 | 内蔵RTC。USB接続時にMac側が `TIME.TXT` を書いて合わせる | 無線なし、外部RTC不要 |
| 動作切替 | VBUSあり＝録音停止・MSC公開、VBUSなし＝録音 | 同時アクセスによるFS破壊を防ぐ |
| UI | ボタン1個（長押しで録音ON/OFF）、LED1個（録音中・電池少） | プライバシー表示を兼ねる |
| サイズ | 目標 直径≦26mm、厚さ≦12mm、重さ≦12g | Omi Consumer: 25.5mm×約15mm／150mAh |
| 削除 | 本体はファイルを消さない。消すのはMac側で、コピー確認後・初期値オフ | ユーザー方針「戻せない削除はしない」 |
