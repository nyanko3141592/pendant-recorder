## ユーザー要件（Naoki確定・変更不可）
1. **有線通信のみ**: BLE・Wi-Fi・NFCなど無線は一切載せない（無線チップ・アンテナも不要）
2. **充電・同期をUSB-C 1本で**: 挿すと初期状態は充電のみ。同期操作をしたときだけMacからUSBドライブ（MSC）として見える（2026-10-24追加）
3. **1日使える**: 起きている間 16時間の録音（目標）
4. **できるだけコンパクト**: ペンダント型。カスタム基板（回路から設計）OK

## 充電のみモード（2026-10-24追加）

- AC充電器、モバイルバッテリー、Macのどれでも、USB-C接続直後は充電のみ。USBドライブを自動公開しない。
- 録音中に接続した場合は録音継続、停止中なら停止を維持する。充電のために録音を始めたり止めたりしない。
- 同期操作案: USB接続中のボタン2回押しで「充電＋同期」へ。既存の長押しは録音ON/OFFに残す。操作方法は暫定。
- 同期時だけDMA停止→ファイル確定/sync→unmount→MSC公開。データ通信できない電源ではMSC接続が成立せず、タイムアウト後に安全に元の録音状態へ戻す。
- 同期終了はMacで安全に取り外してUSBを抜く。USB切断後、MSC要求処理を停止してからFATを再取得し、同期前の録音ON/OFFへ戻す。
- 充電のみではSDの所有者はファーム、同期中はMSC。給電があるだけでは所有者を変えない。
- 充電器/ホストの許容入力電流、USB列挙前・suspendの電源制約、温度制限は別途検証する。録音継続は通常給電時の動作目標で、異常時は安全な停止を優先する。

これは設計仕様。ESP32S3スタブと本番STM32ファームの実装・実機検証はまだ完了していない。
