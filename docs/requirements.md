# 現行要件 — V1 / Rev C0

2026-10-24。[V1の範囲と合格条件](v1-scope.md)が現行仕様。方針は**小さく身につけ、音声を録り、USBで自分のPCへ取り出す**。

|項目|必須要件|
|---|---|
|録音時間|充電なし連続16時間以上。無音も保存。実機未達|
|保存量|16kHz mono以上の圧縮音声36時間以上。電池持ちとは別|
|充電・同期|USB-C。接続時は充電のみで録音状態維持。明示操作時だけ同期|
|ローカル取出し|macOS/Windows/Linuxで登録秘密鍵により復号し通常PCM16 WAVを保存|
|紛失保護|本体は公開鍵のみ、平文音声の本体ストレージ保存禁止|
|電源断|標準形式の短い独立区間を逐次確定。確定分を回収。不完全分は検出・保全|
|削除|PC保存・復号・完全性・永続化検証済みの一致録音だけ自動削除。満杯時の未同期上書き禁止|
|表示|概算残量・充電・録音・同期・異常。2 LED＋1ボタン案。画面なし|
|実装|JLC等の業者実装。完成電池・治具を使い手はんだ/リード加工/圧着なし|
|無線|任意。Rev Cは非搭載。将来無線は別基板改版|
|サイズ|上記を満たす範囲で最小化。現収納ドラフト23.8×34×14mm、成立保証ではない|

## 状態遷移の契約

- 電源接続は録音開始/停止、SD所有権を変更しない。充電器でもPCでも同じ。
- 同期の明示要求で録音停止→ファイル確定→FS解放→MSC公開。MSC中はファームがSDに触れない。
- 正常な取外し・USB切断後、MSC要求を止めてからFSを再取得し、同期前の録音状態に戻る。異常抜去時はFSと区間を点検して復旧する。
- 同期先がない電源だけの場合はMSC成立を待ち続けず、安全に元の録音状態へ戻す。タイムアウト/取消操作はファーム設計時に確定。
- 短押しは状態確認のみ。録音/同期を意図せず切り替えない。長押し録音ON/OFF、USB時の2回押し同期は暫定案。
- 概算残量はADC電圧・校正に基づく段階表示。ゲージSOCや正確な残り時間として見せない。CHGだけで満充電と断定しない。
- USB列挙前/suspend/電流制限/異常温度では安全な給電・停止条件を優先し、通常充電中録音の動作と区別して試験する。

## 保存・公開範囲

音声は標準IMA-ADPCM WAV、短区間ごとの標準age v1暗号化を評価。独自音声形式や独自暗号コンテナを新設しない。実装・実機電源断試験前に最大損失秒数を保証しない。詳細はprotocol/配下を参照。

回路・機構・ファーム・最小ホストCLIを公開。文字起こし・要約・Notion・課金・クラウドはV1必須外。独自成果物MIT、第三者ライセンス保持。
