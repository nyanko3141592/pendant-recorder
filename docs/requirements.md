# 要件（2026-10-24 確定）

> 2026-10-24 回路照合による訂正: 最新の回路原本は [hardware/rev-a/README.md](../hardware/rev-a/README.md)。48ピンSTM32U535CBU6はSDMMC端子がないため試作はSTM32U535RCT6（LQFP64）へ変更。T5838は底面音孔・1.8V専用でレベル変換が必須。BQ25101は約21.8mA設定＋USB給電の負荷分離、USB PHYは専用3.3V。以下は初期調査/見積りを含み、矛盾時は現行Rev A1原本と最新決定記録を優先する。

## ユーザー要件（Naoki確定・変更不可）
1. **有線通信のみ**: BLE・Wi-Fi・NFCなど無線は一切載せない（無線チップ・アンテナも不要）
2. **充電・同期をUSB-C 1本で**: 挿すと初期状態は充電のみ。同期操作をしたときだけMacからUSBドライブ（MSC）として見える（2026-10-24追加）
3. **連続24時間録音**を達成目標とする（[最新の電力・容量予算](runtime-target.md)）
4. **できるだけコンパクト**: ペンダント型。カスタム基板（回路から設計）OK
5. **本体インジケーター必須**: 電池残量、充電、録音、同期、異常が本体だけで確認できること（2026-10-24追加）

6. **v1は個人製作可能な範囲**: 外観の磨き込みは保留。高密度カスタム基板＋シンプルなケースを優先（[製作方針](v1-build.md)）

7. **手元の手はんだゼロを優先**: USB-C・ボタン・表示灯・電池コネクタまで業者実装。電池接続、ケース組立、無はんだ治具での書込み・検証を手元の作業にする（実装受理・NTC構造は未確定）

## 充電のみモード（2026-10-24追加）

- AC充電器、モバイルバッテリー、Macのどれでも、USB-C接続直後は充電のみ。USBドライブを自動公開しない。
- 録音中に接続した場合は録音継続、停止中なら停止を維持する。充電のために録音を始めたり止めたりしない。
- 同期操作案: USB接続中のボタン2回押しで「充電＋同期」へ。既存の長押しは録音ON/OFFに残す。操作方法は暫定。
- 同期時だけDMA停止→ファイル確定/sync→unmount→MSC公開。データ通信できない電源ではMSC接続が成立せず、タイムアウト後に安全に元の録音状態へ戻す。
- 同期終了はMacで安全に取り外してUSBを抜く。USB切断後、MSC要求処理を停止してからFATを再取得し、同期前の録音ON/OFFへ戻す。
- 充電のみではSDの所有者はファーム、同期中はMSC。給電があるだけでは所有者を変えない。
- 充電器/ホストの許容入力電流、USB列挙前・suspendの電源制約、温度制限は別途検証する。録音継続は通常給電時の動作目標で、異常時は安全な停止を優先する。

これは設計仕様。ESP32S3スタブと本番STM32ファームの実装・実機検証はまだ完了していない。

## 本体インジケーター（2026-10-24追加）

必須なのは情報が本体で分かること。以下のLED構成・閾値・操作は回路ドラフトに採用する暫定案で、実機で視認性と消費電流を確認する。

| 表示 | 暫定動作 |
|---|---|
| 電池残量 | 前面の下寄りに小さな3点。短押し1回で3秒表示。>66%は3点、>33〜66%は2点、>10〜33%は1点 |
| 電池低下 | ≤10%は1点をゆっくり点滅。低電圧による停止条件は別に管理。0%でもまだ動作可能なら同じ警告を表示 |
| 録音 | 独立した赤い小点を低輝度で点灯。録音停止中・同期中は消灯。電池表示を出しても録音表示は消さない |
| 充電 | 独立した状態LEDをゆっくり1回ずつ点滅。VBUSだけでなく充電ICの充電信号を確認する |
| USB給電中・非充電 | 状態確認操作後、状態LEDを短時間点灯。満充電・充電停止・異常を一律に「満充電」と解釈しない |
| 同期 | 状態LEDを2回ずつ点滅。同期中の充電状態は短押しで3秒間表示し、その後同期表示へ戻す。短押しでMSCを停止しない |
| 満充電付近 | 残量計の有効なSOC≥95%なら、確認時に3点を2回同時点滅してから点灯。「充電終止確認済み」とは別の目安 |
| 異常 | 状態LEDの速い点滅。SD書込失敗・満杯・充電異常疑い等。録音不能なら録音LEDを消す。異常表示は同期/充電表示より優先 |
| 残量不明 | 残量計の通信失敗・古い値・起動直後の無効値は3点を順番に点滅。0%や満充電に置き換えない |

- 長押しは録音ON/OFF、USB接続中の2回押しは同期。短押し1回は2回押し判定時間（仮350ms）が過ぎてから残量表示。録音やSD所有権を変えない。長押し後に短押しイベントを発生させない。
- 残量計MAX17048のSOCと電圧、充電ICのCHG、VBUS、録音/MSCの実状態から表示する。数値は推定残量であり、正確な残り時間は表示しない。
- 充電中は残量表示を定期的に短時間出す。給電状態がUSB suspendの場合は入力電流制約に従って表示も制限する。
- 常時全点灯はしない。録音表示と低残量/異常警告は確認操作なしでも見えるようにする。輝度・発光窓・日中の視認性は実機で決め、24時間の電力予算にLED負荷を加える。
- 全4デザインに共通適用。既存のコンセプト画像は単一LED時点のため、現仕様をまだ描いていない。

インジケーター用LED/抵抗/GPIOは回路図に追加済み。表示ファーム・筐体の導光部・実機検証は未実装。

## 製品化とMacアプリ（最新決定）

[決定0001](decisions/0001-product-and-v1.md)を適用。v1は無はんだの実装済み基板による実機検証サイクル。Mac同期アプリをOSSで開発し、モデル導入後の文字起こし・要約はローカル処理を基本とする。Notion送信は任意・初期値オフ。機密保護や暗号化を実装済みと主張しない。
