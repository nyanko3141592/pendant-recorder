# V1: 小さく身につけて録音し、USBで自分のPCへ取り出す

2026-10-24確定範囲。外観で大きさを隠す前に、録音機としての完成寸法を小さくする。今回のRev Cは、このV1に向けた回路・配置・収納検討版であり、V1達成品ではない。

## 必須

- 充電なしで16時間以上、16kHz以上・モノラル音声を欠落なく連続記録。無音を省いて持続時間を稼がない。
- USB-C 1本で充電のみ、または明示操作による同期。接続だけでは録音を止めない。MSC中は本体からファイルシステムへアクセスしない。
- 圧縮音声を36時間以上保持。満杯なら状態通知して停止、未同期録音を勝手に消さない。
- 登録PCの秘密鍵で復号。秘密鍵は本体へ置かず、平文音声を本体ストレージへ書かない。
- macOS/Windows/Linuxの最小CLIで同期・復号し、一般的なPCM16 WAVを保存。保存・完全性・永続化確認済みの一致録音だけ自動削除。
- 既存形式の短い独立ファイルを逐次確定し、電源断後に確定済み区間を回収。不完全区間は検出・保全する。IMA-WAV＋age v1は未実装案。
- 電源/録音/充電/異常/概算残量を最低限のLEDとボタンで確認。
- 業者実装済み基板＋完成電池＋完成治具で組立・書込み・検査でき、ユーザーのはんだ・リード加工・圧着が不要。
- 回路、機構、ファーム、ホスト仕様を公開。独自成果物MIT、第三者ライセンス保持。

## V1へ入れない

Bluetooth/Wi-Fi、キャラ表示、画面、スピーカー、文字起こし、要約、クラウド、専用スマホアプリ、サブスクは必須にしない。Rev Cは無線なし。将来Bluetoothを追加する場合は別基板/版になる。ソフト更新だけで対応するとは約束しない。

## 今回の設計と実装の区別

- Rev C回路原本: `hardware/rev-c/`。STM32U535CEU6を使う無線なし比較設計。110mAhを維持し、不明な小型電池に依存しない。
- PCB: 実フットプリントで21×31mmへ配置、両面4層0.8mm。最終配線の合否は `hardware/rev-c/drc.json` と `order-status.json` を優先。
- ケース: 23.8×34×14mmの収納ドラフト。電池コネクタ・裏面部品を積層した結果、12mm目標は未達。装着部、固定、音道、実リード収納、量産公差は未完了。
- 録音ファームと3 OS同期は未実装。16h/36h/暗号/電源断回収の実機合格は未達。

## V1完了条件と工程

1. **設計リリース:** 全ピン/代替機能/パッケージ/電源条件/部品調達の監査、DRC・未接続0、業者実装受理、電池極性・NTC・嵌合部・無加工線材・治具を検証して製造データを出す。
2. **試作:** 基板とケースを製作し、完成治具で初回書込み。Rev CではTC2030接点へ電池を取り付ける前にアクセスする。
3. **最小実装:** マイク→圧縮→標準形式の暗号保存→明示USB同期→復号WAV→検証後削除の一連を動かす。
4. **実機合格:** 16hの全音声を復号、36h分保存（必要なら途中給電）、充電中録音、電源断回収、3 OS同期とキー不一致拒否、満杯/途中抜去/コピー失敗で未同期録音が保全されることを確認。
5. **改版判断:** 電流、温度、収納、操作性、装着感を `docs/validation/` に記録し、より小さい電池・コネクタ・基板へ進む。試作1回目を販売完成版と呼ばない。
