# 書込み経路 — 市販完成ケーブルを使う案

2026-10-24。独自の5点ポゴパッドを廃止し、J3を標準TC2030-NLの6点へ変更。基板側は接点と位置決め穴だけで、コネクタの手はんだ不要。SWOは使わない（MCUのPB3はADFに使用）。

| J3端子 | 接続 |
|---|---|
| 1 | V3 / VTref（電圧参照のみ） |
| 2 | SWDIO |
| 3 | NRST |
| 4 | SWCLK |
| 5 | GND |
| 6 | NC / SWO不使用 |

メーカー図面: https://www.tag-connect.com/wp-content/uploads/bsk-pdf-manager/TC2030-CTX_1.pdf

購入候補: Tag-Connect **TC2030-CTX-NL-STDC14** 完成ケーブル＋対応するSTLINK-V3のSTDC14接続。候補ケーブルのメーカー掲載: https://www.tag-connect.com/product/tc2030-ctx-nl-stdc14-for-use-with-stm32-processors-with-stlink-v3 。デバッガは個別型番・付属ケーブル・OS対応・購入可能性を確認してから購入表を確定。STLINK-V3MINIEも候補だが、名称が似ているだけで同梱物や嵌合を確定扱いしない。

NL型は保持用クリップか支持治具が必要。両面のプローブ挿入空間、位置決め穴、反対面の保持空間を確保する。基板生成ではJ3領域を反対面にも予約したが、実コネクタ/クリップの3D全体は未確認。電池・ケースを取り付ける前に書き込む。電源は本体USB等から供給し、VTrefへ外部給電しない。

市販ケーブルを使える接点へ変更しただけで、手はんだ不要の購入セット全体が確定したわけではない。電流測定用のJST SH対応の完成中継ハーネス/計測治具、NTC接触材、保持治具も別途確定が必要。自作リードのはんだ付けでは解決しない。
