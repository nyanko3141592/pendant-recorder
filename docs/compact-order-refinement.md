## 充電回路の変更条件

[BQ25101資料](https://www.ti.com/lit/ds/symlink/bq25101.pdf)のJEITA温度制御は45℃以上でも条件付き充電を継続するため、パックの0〜45℃条件と一致しない。現回路をそのまま製造へ出さない。

[BQ25170資料](https://www.ti.com/lit/ds/symlink/bq25170.pdf)を変更候補として評価。2×2mm WSON8でピン互換ではない。27kΩ VSETで4.2V、13.7kΩ ISETで約21.9mAを検討するが、50mA未満の追加RC推奨、終止電流、充電電圧公差、供給状況を未解決。直接NTC接続の公称0〜45℃だけで適合扱いしない。
