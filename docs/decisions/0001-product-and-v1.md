# 0001 — 完成デバイス販売と、はんだ不要のv1検証

日付: 2026-10-24 / 状態: ユーザー決定を記録

## 決定

収益の第一軸は、設計・実装・動作確認・組立の手間を引き受けた有線録音デバイスの販売。アプリ課金・API代理販売・サブスクは当面の範囲から外す。任意の寄付は将来追加できるが、寄付先は未設定。

回路・基板・筐体・ファームウェア・Mac同期アプリのソースを公開する。独自成果物はMITを採用し、第三者のライセンスを維持する。完成品の購入は、公開設計を使うための必須条件にしない。

Macアプリを製品構成に含める。以前の「アプリなし」はスマホアプリ・クラウドへの依存を避ける意図として更新する。録音・USBドライブとしての取り出しに専用アプリを必須にせず、Macアプリはコピー・時刻合わせ・ローカル文字起こし・ローカル要約を簡単にする。

モデル導入後の基本処理はオフラインで動かす設計とし、APIキー・アカウント・課金契約を必須にしない。Notion等への外部送信は任意かつ初期値オフ。音声や文字起こしを自動送信しない。機密情報が入るため、生の実録音を公開検証ログへ入れない。ローカル処理は端末紛失・USBドライブの平文読出しまで防ぐものではなく、暗号化・アクセス制御は未実装と明示する。

v1は販売完成版ではなく「業者実装済み基板を入手 → ファームを書込む → 実機で試す → 結果を残す → 改版する」最初の検証サイクル。24時間録音、15mm厚上限、指示操作だけでMSCへ切替、状態表示の要件は維持する。

## 手元で行う作業の境界

許容: 購入、電池コネクタ接続、絶縁材/熱接触材/ガスケットの貼付、ネジ組立、USB接続、市販完成ケーブルまたは業者実装済み治具による書込み・測定。

不可: 手はんだ、電池リードの切断/圧着、細線の追加、USB固定脚だけ後付け、NTCの後付けはんだ、書込み治具を自分ではんだ付けして作ること。

業者が実装できない部品は代替設計か別の実装サービスを選ぶ。「その部品だけ自分で付ける」で解決しない。ポゴ治具も完成品・組立済みケーブル・実装済み治具基板まで調達経路を確定する。
