# BQ25185 ILIM100によるUSB入力回路の簡略化

日付: 2026-10-28

## 採用する電気方針

- U3 BQ25185DLHRを継続使用する。
- R42を130 kΩから24 kΩへ変更する。
- BQ25185 Rev.B Table 6-1に従い、電池電圧4.2 V、入力電流制限ILIM100を選ぶ。
- TI保証値はVIN=5 Vで入力電流制限80/90/98 mA（min/typ/max）。これは充電電流だけでなくIN端子からSYSと電池へ流れる合計入力に作用する。
- 約44.12 mAの充電電流設定と、電池パック内蔵保護基板は維持する。

## 撤去した回路

MAX4995と、その可変電流設定・起動ラッチ・サスペンド／復帰パルス回路を撤去した。対象はU13、U14、U15、Q5、Q6、Q7、R44～R47、C31～C33の13点。これらをBOM、回路図、基板フットプリントから除外した。

## 温度保護

今回の変更では、電池内蔵NTCのB値とR-T公差が未確認なため、内蔵NTC直結への切替は行わない。現行の独立温度ガードを維持する。量産版で基板温度センサーを削除する条件は、電池メーカーによる内蔵NTC仕様の文書化と実ロット確認である。

## 現在の検査状態

- 回路図ERC: 0件
- 回路図―PCBパリティ: 0件
- PCB DRC: 未合格。旧U13直列位置を撤去したため、VBUSからU3 INまでの安全な再配線が未完。試した直結配線は既存信号との交差を生じたため採用せず削除した。
- 現PCB、旧Gerber、旧BOM/CPLは発注禁止。新しい電源経路を配置・配線し、DRC 0、未配線0、CAM再出力を完了してから発注候補を再生成する。

この状態は、危険な仮配線を残して見かけ上発注可能にするより、意図的にHOLDとする。
