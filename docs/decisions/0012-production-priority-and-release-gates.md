# 量産化の優先順位とリリース条件

日付: 2026-10-28

## 優先順位

1. **安全性** — 発火、過充電、過放電、短絡、USB異常、温度異常を防ぐ。未確認案は不採用。
2. **連続16時間録音** — DTP401525-XE（110mAh）固定、16kHz以上・モノラル・無音込みの連続録音。未実測は未確認。
3. **量産時の作業不要** — 基板業者への一括発注とし、ユーザーの部品調達・支給・手はんだ・圧着・配線加工をなくす。
4. **必須機能** — 暗号化30時間保存、USB-C一端子、3 OS取込み・復号、無線・専用充電台不要。
5. **量産の継続性** — 標準部品、代替性、通常工程、全成果物の版一致。
6. **ネックレスとしての実用性** — 姿勢、紐受け強度、積層方向、摩耗・疲労、USB-C方向、外観。
7. **小型化** — 上位条件内で最小化。30×32×15mmは目標で絶対上限ではない。
8. **原価・充電速度など** — 上位条件を損なわない範囲だけで最適化。

両立しない場合は上位を守る。根拠のない項目は未確認とし、計算・シミュレーション・非実機試験・実測を区別する。注文、支払い、製造データアップロード、業者連絡は行わない。

## 今回反映した回路変更

- BQ25185のハードウェア設定を4.2 V / ILIM100へ固定した。R42は24 kΩ。TIの5 V時入力電流制限は80/90/98 mA（min/typ/max）。
- 専用USB入力リミッタ、ラッチ、監視ICと周辺部品13点、および不要な制御抵抗3点を削除した。
- USB VBUSから充電器入力までを標準0402の0 Ωリンク R51へ置換した。
- 充電電流設定は約44 mAを維持し、110 mAhパックの連続充電上限110 mAに対して余裕を取った。
- 回路図ERC 0、基板DRC 0、未接続 0、回路図/基板不一致 0を確認した。基板実装点数は71点。

## 調達・組立方針

- JLCPCBには基板上の全電子部品を実装させる。ユーザーが抵抗、IC、MOSFET、温度センサを購入・はんだ付けする構成にはしない。
- ユーザー側は、保護回路付き電池の装着、ケースへの収納、紐の取り付けだけを目標とする。
- 固定電池DTP401525-XEのP2白線は公開仕様で内蔵10 kΩ NTCと確認できたため、J2 pin2から`BAT_TS`へ直結する。基板TH1とケース内熱伝導パッドは使用しない。
- 内蔵NTCの正確なB値、R-T公差、ロット差、および実装状態でのhot/cold遮断・復帰は未実測である。これらが5台EVTで合格するまで充電既定無効を維持する。

## 発注を止める残課題

1. 固定電池内蔵NTCについて、0/10/25/35/45 °CのR-T実測、ロット差、cold/hot/open/short、起動時、brownout時の充電停止・復帰を5台EVTで確認する。
2. 公開資料で確認済みの保護回路、3極コネクタ極性、10 kΩ NTCを受入仕様へ転記し、公開資料にないB値/R-T公差は実測受入範囲として管理する。個別問い合わせを量産成立の前提にしない。
3. 全71リファレンスの型番/JLC番号対応は作成済み。MCUはU585へ同期済みだがJLC通常在庫の継続性は未確認。未再取得行、向き、公開価格の残りをアップロードせずに閉じる。実発注画面でしか決まらない費用は未確認とする。
4. 5台のEVTでUSB-Cケーブル嵌合、充電、録音、16時間目標、温度、ケース内クリアランスを検証する。
5. 現正本のhole-over-padは3か所（U1.40 PDM_DATA、U1.10 VBUS_N、U3.9 CHG_N）。通常viaへの局所再配線探索ではDRC0を維持できなかったため、6層ENIGでJLCPCBが公開している0.15 mm樹脂充填・平坦化・銅キャップPOFVを単一試作候補とする。公開能力との寸法一致は確認済みだが、実基板の平坦度、はんだボイド、open/short、実装歩留まりは5台EVTまで未確認。
6. U10はリード付きTPS22917DBVT（SOT-23-6）へ変更済みで、CTはデータシートに従いopen、QODはSD_V3へ接続した。電力、立上り、逆流、放電、ケース干渉は実機未確認。
7. 合格後にのみ量産用CAMをリリースする。旧order-candidateは使用禁止。
