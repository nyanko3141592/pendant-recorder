# 0007: 丸形制約を外し、既製小型完成電池を優先

2026-10-25。ユーザーが調達性を考慮し非丸形・小型電池を許可。丸形150mAhへの固定を解除する。USB-C、連続録音16h以上、36h保存、暗号化、無はんだ、ペンダントとしての小ささは維持。特定の電池への採用確定ではない。D1.1/D2は比較原本、発注不可を維持する。

## 容量と16hのトレードオフ

使用可能容量70%という未検証の仮定では、110mAhは平均4.81mA以下、150mAhは6.56mA以下で16h。従来の平均5mA開発目標では110mAhは15.4hとなり条件未達。110mAh候補は平均4.5mA以下を検証目標に置くと計算17.1hだが、ファーム実装・電池放電試験前に達成としない。無音録音省略では補わない。

## サイズとコストの扱い

角形電池に丸形基板を無理に合わせず、完成パック・配線・コネクタを起点に基板外形も比較する。現D25.5mmケースへこれらの角形パックが入るとは扱わない。TinyCircuits最大23×22mmは対角約31.8mmなので、現円形ケースへ平置きできない。形状変更後の外形・層数は配置/配線後に判断し、4層化できると先に約束しない。

EZ3掲載単価なら電池5個は6,260円（送料別）。TinyCircuitsなら5個$24.75（予算為替160円で3,960円、海外送料/税別）。どちらも完成電池の単価が見える点で特注丸形より比較しやすい。一方、現在の6層両面PCBA初期費用は電池変更だけでは下がらない。旧費用表はD1.1の予算履歴として保持し、未成立の新設計総額に流用しない。

次はEZ3の完成図面/温度条件・コネクタの実装調達を確認し、150mAh SH品の国内配送可能性と比較する。充電ICの45〜60℃挙動との不整合は電池形状変更では解消しない。採用比較後に基板/CADへ反映する。
