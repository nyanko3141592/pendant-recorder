# DTP401525-XE接続・温度監視方式

状態: **電池内蔵NTC直結方式を採用。電気検査合格、実温度試験は未合格。**

## 決定

- 電池はDTP401525-XEの出荷時3極プラグ（Molex 781720003）を、基板実装済みMolex 781710003へそのまま挿す。購入者は配線加工、圧着、はんだ付けをしない。
- DTP401525-XEの中央pin（P2白線）は公開仕様で内蔵10kΩ NTCと確認できたため、J2 pin2から`BAT_TS`へ直結する。基板側TH1とケース内熱伝導パッドは削除する。
- 正確なB定数、抵抗公差、ロット差は未公開なので温度換算値を保証値にしない。受入検査で0℃、10℃、25℃、35℃、45℃の実抵抗を測り、抵抗窓と実温度遮断を両方認定する。
- NTC配線のため基板上端を0.5mm拡張し、完成基板外形を27.5×27.5mmとした。追加viaや部品はなく、ERC/DRC/parity/unconnectedは全0。
- TLV7042によるcold/hotのwired-AND charge inhibitを維持し、MCUが停止・起動途中でも異常温度で充電許可されない構成を試作する。BQ25185の固定TS抵抗だけを電池温度監視と呼ばない。

## 採用理由

固定電池自身のNTCはセルへ組込み済みで、ケース公差、柔軟パッド、接触圧、圧縮永久歪みへ依存しない。基板実装NTC方式より安全応答と量産再現性が高く、購入者作業も増えない。R-T曲線と完成品遮断は未実測なので、実測合格までは充電を有効化しない。

## 電気的な注意

比較器の抵抗窓7.5kΩ..20kΩは維持する。ただし電池内蔵NTCのB定数が未公表なので、旧基板NTC B3380から計算した温度値を流用しない。

試作時は抵抗置換によるcold/hot/open/short、電源投入・brownout、MCU停止を先に試験し、その後、恒温環境で電池表面温度とセンサー温度を同時計測する。充電停止は安全側、復帰には十分なhysteresisを持たせ、境界でチャタリングしないことを確認する。

## 機構ゲート

ケース確定前に次を満たす。

1. 3極純正ハーネス、J2、電池、セパレータを同一組立モデルに含める。熱伝導パッドは使わない。
2. 電池最大4.2mm厚と膨張余裕を妨げず、局所的な硬い突起でパウチを押さない。
3. 電池を接着せず、ケースを開けばコネクターを抜いて電池を外せる。
4. A1 mini/PLAの公差ばらつきでもハーネスを挟まず、NTC線へ引張荷重を掛けないことを確認する。
5. 純正15±3mm配線とプラグの実測形状を使い、最小曲げ・挟み込み・引張りを確認する。公開資料だけで不足する寸法は試作電池の受入測定値として管理する。

## 未合格事項

- 電池内蔵NTCのB定数、抵抗公差、ロット差、open/short故障時の完成回路挙動
- TLV7042の実common-modeにおける停止/復帰しきい値
- 電池内蔵NTCとセルの熱応答遅れ
- 781720003プラグを含む純正ハーネスの完全な最大包絡
- 充電中の温度試験、異常試験、16時間実測

したがって、この決定はPCB/ケースを一体設計する入力であり、充電安全や製品成立の保証ではない。
