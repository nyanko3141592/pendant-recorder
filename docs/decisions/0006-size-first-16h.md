# 0006 — 小ささ最優先、連続16時間以上、USB-C、無線は任意

2026-10-24、最新ユーザー指示に基づく要件変更と選定提案。決定0004/0005の24h必須・内蔵無線必須より優先。Rev A/Bの回路と発注不可の記録は維持し、この文書だけで新回路の成立・採用を宣言しない。

## 確定した優先順位

1. USB-C充電、連続録音16時間以上を満たし、その範囲で完成外形を最小化する。無音を落として時間達成とは扱わない。
2. BluetoothはNice to have。面積・厚さ・電池容量・調達性を悪化させるなら外す。将来無線のための空きやソケットも必須にしない。
3. 既存のUSBによるローカル音声取出し、圧縮音声36h保存、鍵による紛失保護、電源断回収、最低限の状態表示、無はんだ組立は撤回されていないため維持。
4. キャラの表示器は外観候補のみ。小ささ優先の基準案には載せず、状態LEDのみ。表示器を採用決定した扱いにしない。

## なぜ現Rev Bが長いか

現案の完成外形24.8×46.5×12.8mmは、22×43.5mm基板、無線モジュール、RF禁止領域、15.5×27×4.2mm電池、PHコネクタと未加工リード、USBの積み重ね・配置条件による。16h化だけで基板が縮むわけではない。各要素の寄与を加算して削減寸法を保証しない。

## 比較する構成

|案|扱い|小型化の見込みと未確認点|
|---|---|---|
|無線なし、小型USB MCU＋SPI SD|次の配置検討の基準案|モジュールとRF禁止領域を外せる。STM32U535のUFQFPN48 7×7mm等を再評価。USB/ADF/SPI/暗号処理、ピン競合、Flash/RAM、電源回路を全て確認してから型番確定|
|小型BLEモジュール＋SPI SD|同じ完成外形へ収まる場合だけ比較|USB搭載、アンテナ禁止領域、電池との距離、JLC実装受理まで含めて評価。単体寸法の小ささだけで採用しない|
|現Rev B|比較原本|配線試行・検証用に保持。現サイズを新要件の最小案とはしない|

旧48ピンSTM32の不採用理由はSDMMC端子不足だった。今回はSPI SDなので再検討できる。ただし回路は別設計となり、そのまま置換できない。BGAも業者実装できれば比較対象だが、逃げ配線・基板仕様・費用・再調達を含む。手実装難度を理由に大きな部品へ固定しない。

追加の縮小候補: 電源電圧の合うマイクでレベル変換と専用LDOを減らす、概算残量をADCで測って専用ゲージを省く、同じ安全条件で電源部品を統合する。いずれも未採用。ADC残量は負荷と電圧曲線の校正が必要。保護回路・NTC・USB保護を小型化目的で省略しない。調査したICS-41350はメーカーEOLなので新規採用候補から外す。

## 電池の成立条件

使用可能率70%という従来の仮定による感度計算。実測予測・保証ではない。電池端平均電流はマイク、処理、圧縮、age暗号化、短区間確定、SD busy、表示、電源損失を含む。

|公称容量|16hの平均電流上限|20hの平均電流上限|
|---:|---:|---:|
|60mAh|2.625mA|2.10mA|
|80mAh|3.50mA|2.80mA|
|110mAh|4.8125mA|3.85mA|

例えば3mAなら16hに必要な公称容量は68.6mAh、20hなら85.7mAh。110mAhを16hで使う余裕が基板簡素化に有利な場合もある。最初から60mAhを買える完成パックとして扱わない。60/80mAhは未調達の容量比較枠。国内で少数再購入できる保護付き・コネクタ付きパックの最大寸法、端子極性、リード長、許容充電電流を照合するまで採用しない。

既存DTP401525(PHR)110mAhは電池本体最大15.5×27×4.2mm。100mmリードとPHコネクタは別。実寸の収まりを確認するまで、細長いセル寸法だけで20mm角を約束しない。短いリード/小型コネクタが必要なら供給元で完成加工されたパックを調達し、ユーザーによるはんだ・圧着は求めない。供給可否は未確認。

## 外形予算（配線・収納前の目標、実現寸法ではない）

- 第一段階: **22×34×12mm**。現Rev Bの直方体包絡14.761cm³に対し8.976cm³、約39%減。長さ約27%減。PCB目安19×31mmで部品配置を検討する。
- より攻める枠: **20×32×12mm**、7.68cm³、約48%減。内側17.6×29.6mm（壁1.2mm仮定）は電池だけでも余裕が小さい。PH/配線/USB/取付/音道を入れた成立は未確認。
- 厚さ12mmは、壁2.4＋電池4.2＋PCB0.8＋上面部品3.0＋絶縁/余裕1.0=11.4mmという粗い予算。裏面部品・嵌合コネクタ・膨張・保持機構が同じ断面へ重なれば超過する。余裕0.6mmで成立したと扱わない。
- Omiと同等の円形に固定しない。現110mAhパックの長さ27mmは直径25mmの本体内寸に収まらない。Omi同等の投影面積へ行くには電池調達から再選定が必要。

## 次に成立を確認する順番

1. 電池完成パックの調達とコネクタ/リード実寸、USBソケット、NTC接触、ケース保持を先に寸法拘束へ入れる。
2. 無線なし案と無線あり案を同じ部品条件で配置比較。小型MCUの全ピン・メモリ・暗号処理・電源を照合。MCU/電池の採用確定前に比較結果を相談。
3. 選択案だけ別リビジョンで配線/ERC/DRC/製造受理へ進める。未配線図を発注可能と呼ばない。
4. 同じ録音・暗号・保存ワークロードで電池端平均/ピーク電流を測り、容量と最終外形を確定。実機で16h以上の音声が完全に復号・回収できることを合格条件とする。目標は可能なら20h相当の余裕。
